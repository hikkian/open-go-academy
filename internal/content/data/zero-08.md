# Мини-проект и обзор Zero

## Что ты сделаешь

Ты соберёшь маленький мини-проект из трёх функций: `countPassing` считает проходные оценки, `summarizeScores` строит сводку по списку, `reviewStatus` выбирает статус по сводке. Каждая функция отвечает за одно и обрабатывает пустой ввод по явному правилу.

## Одна функция — одна задача

Программа из нескольких функций читается легче, когда каждая делает одно дело. Вот функция, которая возвращает тип, описанный структурой:

```go
package main

import "fmt"

type Point struct {
    X int
    Y int
}

func midpoint(a, b Point) Point {
    return Point{X: (a.X + b.X) / 2, Y: (a.Y + b.Y) / 2}
}

func main() {
    fmt.Println(midpoint(Point{X: 0, Y: 0}, Point{X: 4, Y: 2}))
}
```

Вывод: `{2 1}`. Структура `Point` объединяет связанные поля; тип результата записан явно, как и у любой функции.

## Пустой ввод и граница

Пустой список — законный вход, а не ошибка. Проверь длину раньше, чем обращаться к элементам: `scores[0]` для пустого среза аварийно остановит программу.

Граница тоже важна. Правило «оценка 60 и выше — проходит» включает 60 ровно. Условие `scores[i] >= 60` даёт именно это, а `> 60` потеряло бы 60.

> **Важно.** Пустой ввод и граничное значение проверяются отдельно: их легко пропустить, когда пишешь основной случай.

## Средний балл и целые числа

Деление целых чисел отбрасывает дробную часть: `3 / 2` даёт `1`. Для среднего нужно число с дробной частью:

```go
package main

import "fmt"

func main() {
    total, count := 3, 2
    fmt.Println(total/count, float64(total)/float64(count))
}
```

Вывод: `1 1.5`. Поэтому поле `Average` имеет тип `float64`, а сумму приводят к нему перед делением.

> **Типичная ошибка.** `total / count` при целых `total` и `count` даёт округление вниз, а не среднее. Преобразуй хотя бы одно число в `float64`.

## Если что-то пошло не так

- `index out of range [0] with length 0` → обращение к `scores[0]` для пустого среза. Сначала проверь `len`.
- `invalid operation: ... (mismatched types int and float64)` → оба операнда должны быть одного типа: преобразуй явно.
- `missing return` → в одной из веток функция не возвращает значение.

## Практика

Три задания. Функции проверяются на входах из блока «Ожидаемый вывод»; закрытые примеры видны только в «Проверить».

### Задание 1 · Посчитай проходные баллы

**Цель.** Вернуть число оценок, которые не меньше 60; пустой ввод даёт 0.

**Ожидаемый вывод** — входы `[59, 60, 61]` и пустой срез:

```text
2
0
```

**Шаги.**
1. Выбери задание «Посчитай проходные баллы»: в файле есть `countPassing` с `return 0`.
2. Заведи счётчик `count := 0`.
3. Пройди по `scores` и для каждой оценки `>= 60` увеличь счётчик на 1.
4. Верни `count`.
5. Нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два числа в «Результате»: `2` и `0`; все три критерия зелёные.

**Если не принято.**
- Оценка 60 не засчитана → условие должно быть `>= 60`, а не `> 60`.
- Для пустого ввода ошибка → проверь, что счётчик возвращается без обращения к элементам.
- Закрытый пример с оценкой 0 засчитан → нижняя граница 60, а не 0.

> **Подсказка.** Один цикл и одно условие внутри него: `if s >= 60`.

### Задание 2 · Собери сводку результатов

**Цель.** Вернуть `ScoreSummary` с количеством, суммой, средним, минимумом и максимумом; для пустого ввода все числа равны 0 и `HasScores` равно `false`.

**Ожидаемый вывод** — входы `[10, 20]` и пустой срез. Каждая сводка печатается как JSON-объект в одну строку:

```text
{"Count":2,"Total":30,"Average":15,"Minimum":10,"Maximum":20,"HasScores":true}
{"Count":0,"Total":0,"Average":0,"Minimum":0,"Maximum":0,"HasScores":false}
```

**Шаги.**
1. Выбери задание «Собери сводку результатов»: тип `ScoreSummary` и формула уже заданы в файле.
2. Для пустого среза верни `ScoreSummary{}` — нули и `HasScores: false`.
3. Для непустого среза посчитай `Count`, `Total`, `Minimum` и `Maximum` в одном цикле.
4. `Average` — это `float64(Total) / float64(Count)`.
5. `HasScores` — `true` для непустого среза.
6. Нажми «Запустить» и сравни обе строки с блоком выше.
7. Нажми «Проверить».

**Как проверить себя.** Две строки JSON в «Результате»; все три критерия зелёные.

**Если не принято.**
- Среднее выходит целым там, где ждали дробное (например, 2.5 для `[2, 3]`) → сумма и количество не приведены к `float64` перед делением.
- Для непустого среза минимум 0 → начальное значение минимума нужно взять из первого элемента, а не из нуля.
- Красная «закрытый пример» на пустом срезе → проверь, что `HasScores` равно `false`, а не `true`.

> **Подсказка.** Обрабатывай первый элемент отдельно: он задаёт начальные минимум и максимум.

### Задание 3 · Объясни результат сводки

**Цель.** Вернуть `no data`, если `HasScores` равно `false`; иначе `ready`, если `Average` не меньше 60, и `review` в остальных случаях.

**Ожидаемый вывод** — входы: пустая сводка и сводка со средним 60:

```text
"no data"
"ready"
```

**Шаги.**
1. Выбери задание «Объясни результат сводки»: в файле есть `reviewStatus` с `return ""`.
2. Сначала проверь `summary.HasScores`: если `false`, верни `no data`.
3. Затем сравни `summary.Average` с 60 через `>=`: при совпадении верни `ready`.
4. Во всех остальных случаях верни `review`.
5. Нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два слова в кавычках в «Результате»: `"no data"` и `"ready"`; все три критерия зелёные.

**Если не принято.**
- Для пустой сводки выходит `review` → проверка `HasScores` должна идти первой.
- Среднее 60 получает `review` → условие должно быть `>=`.
- Закрытый пример со средним 59 даёт `ready` → сравни с 60, а не с 50.

> **Подсказка.** Порядок веток важен: сначала `HasScores`, потом `Average`.
