# JSON API и REST-ресурсы

## Что ты сделаешь

Ты напишешь три функции, которые описывают HTTP-контракт ресурса без сервера: `MethodStatus` выберет статус по методу, `IsIdempotentMethod` скажет, безопасно ли повторять запрос, `ResourceLocation` построит адрес ресурса и экранирует его имя. Все три работают со строками и не открывают соединений.

## Метод задаёт смысл, статус — результат

HTTP-метод говорит, что клиент хочет сделать: получить (`GET`), создать (`POST`), заменить (`PUT`), изменить часть (`PATCH`), удалить (`DELETE`). Статус ответа говорит, что получилось. Константы для методов есть в пакете `net/http`:

```go
package main

import (
    "fmt"
    "net/http"
)

func main() {
    fmt.Println(http.MethodGet, http.MethodDelete)
}
```

Вывод: `GET DELETE`. Эти константы — точные строки: `get` в нижнем регистре уже другой метод по контракту задания.

> **Важно.** Статус 200 после `POST` означает «выполнено», а 201 — «создан новый ресурс». Клиент, который ждёт 201, по 200 не узнает, создана ли запись.

## Таблица метода и статуса

Соответствие метода и статуса удобно записывать явным `switch`. Ветка по умолчанию покрывает неизвестные методы, и её результат тоже часть контракта:

```go
package main

import "fmt"

func main() {
    for _, m := range []string{"GET", "DELETE"} {
        switch m {
        case "GET":
            fmt.Println(m, 200)
        case "DELETE":
            fmt.Println(m, 204)
        }
    }
}
```

Вывод: `GET 200` и `DELETE 204`. Успешное удаление не возвращает тела, поэтому выбран статус 204.

## Идемпотентность

Метод идемпотентен, если повтор того же запроса даёт тот же результат на сервере. `PUT` с одним и тем же телом можно повторить: ресурс останется в том же состоянии. `POST` обычно создаёт ещё одну запись при каждом повторе, поэтому он не идемпотентен. Это свойство смысла, а не совпадение статусов.

> **Типичная ошибка.** Считать метод идемпотентным, потому что ответ при повторе такой же по статусу. Важно, изменился ли ресурс на сервере, а не текст ответа.

## Экранирование сегмента пути

Имя ресурса может содержать `/`, пробелы и другие символы. Если вставить его в путь как есть, `/` создаст новый сегмент. `url.PathEscape` кодирует такие символы, и значение остаётся одним сегментом:

```go
package main

import (
    "fmt"
    "net/url"
)

func main() {
    fmt.Println(url.PathEscape("a/b"), url.PathEscape("go"))
}
```

Вывод: `a%2Fb go`. Слэш превращён в `%2F`, поэтому путь `/links/a%2Fb` всё ещё ведёт к одному ресурсу.

## Если что-то пошло не так

- `undefined: url` → не добавлен импорт `"net/url"`.
- `missing return` → ветка `switch` без значения; добавь `default`.
- Путь получает лишний сегмент → имя вставлено без экранирования.
- `imported and not used: net/http` → импорт есть, а константы не использованы.

### Задание 1 · Сопоставь метод и статус API

**Цель.** Для `GET` и `HEAD` вернуть 200, для `POST` — 201, для `PUT` и `PATCH` — 200, для `DELETE` — 204. Для любого другого метода — 405.

**Ожидаемый вывод** — входы `GET` и `POST`:

```text
200
201
```

**Шаги.**
1. Выбери задание «Сопоставь метод и статус API»: в файле есть `MethodStatus` с `panic("TODO")`.
2. Напиши `switch method` с ветками по значениям из контракта. Сравнение точное.
3. Каждый метод из условия получает свой статус.
4. Ветка по умолчанию возвращает 405.
5. Нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два числа: `200` и `201`; все три критерия зелёные.

**Если не принято.**
- Для `DELETE` выходит 200 → по контракту удаление даёт 204.
- Для `get` выходит 200 → сравнение должно быть точным, без приведения регистра.
- Для `OPTIONS` ничего не возвращается → ветка по умолчанию должна дать 405.

> **Подсказка.** Несколько значений в одной ветке `case` перечисляются через запятую.

### Задание 3 · Сформируй URI ресурса

**Цель.** Вернуть `/links/` и экранированное имя ресурса. Пустое имя или имя с пробельным символом — пустая строка.

**Ожидаемый вывод** — входы `green` и `go`:

```text
"/links/green"
"/links/go"
```

**Шаги.**
1. Выбери задание «Сформируй URI ресурса»: в файле есть `ResourceLocation` с `panic("TODO")`. Добавь импорт `"net/url"`.
2. Если `alias` пустой, верни пустую строку.
3. Пройди по символам `alias` через `range`. Если встретился пробел, табуляция, перевод строки или возврат каретки, верни пустую строку. Других импортов не нужно.
4. Иначе верни `"/links/" + url.PathEscape(alias)`.
5. Нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Две строки в кавычках: `"/links/green"` и `"/links/go"`; все три критерия зелёные.

**Если не принято.**
- Имя `a/b` даёт `/links/a/b` → имя не экранировано: используй `url.PathEscape`.
- Имя с пробелом даёт непустую строку → пробельный символ должен давать пустой результат.
- Для точки в имени выходит пустая строка → точка допустима, отказ только для пустого и пробельного имени.

> **Подсказка.** Сначала две проверки на отказ, потом одна строка сборки пути.
