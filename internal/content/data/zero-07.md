# Массивы, срезы и простые данные

## Что ты сделаешь

Ты напишешь три функции над списками чисел: сумма значений, подсчёт значений выше порога и копия списка с добавленным элементом. Все три работают с данными, которые получают на входе, и не меняют исходный список.

## Массив и срез

Массив имеет фиксированную длину: `[3]int` — ровно три числа. Срез (slice) `[]int` — окно в массив: у него есть длина (`len`) и ёмкость (`cap`), то есть сколько элементов помещается без нового массива.

```go
package main

import "fmt"

func main() {
    arr := [3]int{1, 2, 3}
    s := arr[:]
    fmt.Println(len(arr), len(s), cap(s))
}
```

Вывод: `3 3 3`. Срез `arr[:]` смотрит на тот же массив, а не на копию.

> **Важно.** Срез не владеет данными сам: изменение элемента через срез меняет и массив, и все другие срезы на него.

```go
package main

import "fmt"

func main() {
    base := []int{1, 2, 3}
    view := base[:2]
    view[0] = 9
    fmt.Println(base, view)
}
```

Вывод: `[9 2 3] [9 2]`. Короткий вид `view` отдал в базу изменение.

## append: присваивай результат

`append` добавляет элементы и возвращает срез. Результат нужно сохранить: при нехватке ёмкости Go выделит новый массив, и старое имя уже не увидит новые элементы.

```go
package main

import "fmt"

func main() {
    var values []int
    values = append(values, 4)
    values = append(values, 5)
    fmt.Println(values, len(values))
}
```

Вывод: `[4 5] 2`. Переменная `var values []int` — nil-срез: пустой, но его можно передавать и добавлять в него.

> **Типичная ошибка.** Написать `append(values, 4)` без присваивания. Результат теряется, а `values` остаётся прежним.

## Независимая копия: copy

`copy(dst, src)` копирует элементы из `src` в `dst` и возвращает их число. Для копии `dst` создают заранее нужной длины через `make`:

```go
package main

import "fmt"

func main() {
    src := []int{1, 2, 3}
    dst := make([]int, len(src))
    n := copy(dst, src)
    dst[0] = 7
    fmt.Println(n, src, dst)
}
```

Вывод: `3 [1 2 3] [7 2 3]`. Исходный срез не изменился, потому что `dst` — отдельный массив.

## Если что-то пошло не так

- `index out of range [3] with length 3` → индекс за пределами среза. Не обращайся к `values[i]` без проверки `len`; для обхода проще `range`.
- `declared and not used` → переменная объявлена и не используется; удали её или используй.
- `cannot use ... as []int value` → функция возвращает не срез, а число или другой тип.
- Закрытый пример с пустым вводом падает → проверь, что код не читает `values[0]` при `len(values) == 0`.

## Практика

### Задание 1 · Сложи значения

**Цель.** Вернуть сумму всех элементов `[]int`; для пустого среза результат равен 0.

**Ожидаемый вывод** — входы `[1, 2, 3]` и пустой срез:

```text
6
0
```

**Шаги.**
1. Выбери задание «Сложи значения»: в файле есть `sumSlice` с `return 0`.
2. Заведи переменную `total := 0`.
3. Пройди по срезу: `for _, v := range values { total += v }`.
4. Верни `total`.
5. Нажми «Запустить» и сравни два числа с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** В «Результате» два числа: `6` и `0`; все три критерия зелёные.

**Если не принято.**
- Для пустого среза выходит не 0 → начальное значение `total` должно быть 0.
- `index out of range` → не используй индексы за пределами среза; обойди элементы через `range`.
- Закрытый пример с отрицательными числами не совпал → сложение не должно пропускать отрицательные значения.

> **Подсказка.** В `for _, v := range values` подчёркивание означает «индекс мне не нужен».

### Задание 2 · Посчитай выше порога

**Цель.** Вернуть число значений строго больше `threshold`; равные порогу не считаются, пустой ввод даёт 0.

**Ожидаемый вывод** — входы: срез `[10, 11, 12]` с порогом `10`, затем пустой срез с порогом `10`:

```text
2
0
```

**Шаги.**
1. Выбери задание «Посчитай выше порога»: в файле есть `countAbove` с `return 0`.
2. Заведи счётчик `count := 0`.
3. Пройди по `values` и для каждого значения с условием `v > threshold` увеличь `count` на 1.
4. Верни `count`.
5. Нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два числа в «Результате»: `2` и `0`; все три критерия зелёные.

**Если не принято.**
- Значение, равное порогу, засчитано → условие должно быть строгим: `>`, а не `>=`.
- Пустой ввод даёт не 0 → проверь, что счётчик начинается с нуля и возвращается без особых случаев.
- Закрытый пример с порогом 0 не совпал → проверь знак сравнения у отрицательных значений.

> **Подсказка.** Одна проверка внутри цикла: `if v > threshold`.

### Задание 3 · Добавь элемент в копию

**Цель.** Вернуть новый срез: копию `values` с `value` в конце. Исходный срез не меняй.

**Ожидаемый вывод** — входы: срез `[1, 2]` и значение `3`, затем пустой срез и значение `9`:

```text
[1,2,3]
[9]
```

**Шаги.**
1. Выбери задание «Добавь элемент в копию»: в файле есть `appendCopy` с `return nil`.
2. Создай срез нужной длины: `out := make([]int, len(values)+1)`.
3. Скопируй элементы: `copy(out, values)`.
4. Запиши новое значение в последнюю позицию: `out[len(values)] = value`.
5. Верни `out`, нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два среза в квадратных скобках без пробелов: `[1,2,3]` и `[9]`; все три критерия зелёные.

**Если не принято.**
- Вывод `[1,2]` без `3` → значение не записано в результат.
- Закрытый пример с nil-срезом падает → `copy` и `make` работают и с пустым срезом; специальный случай не нужен.
- Исходный срез изменился → не записывай элементы в `values`, работай только с `out`.

> **Подсказка.** `make([]int, n)` создаёт срез из `n` нулей; `copy` перезапишет первые элементы исходными значениями.

## Итог

- Массив имеет фиксированную длину, срез — окно в массив с длиной и ёмкостью.
- `append` возвращает срез, результат нужно сохранить; `copy` копирует элементы и даёт независимую копию.
- Пустой срез — законный вход: сумма 0, счётчик 0, копия из одного элемента.
