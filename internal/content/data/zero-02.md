# Значения, переменные и простые типы

## Что ты сделаешь

Ты напишешь функцию `formatGreeting`, которая получает имя и возвращает готовую фразу: сначала склеиванием текста, потом через форматирование, потом для строки чека. Заодно научишься хранить данные в переменных и отличать текст от числа — без этого ни одна проверка в курсе не пройдёт.

## Значение и тип

Значение (value) — конкретная информация: `"Алия"`, `27`, `true`. Тип (type) говорит, что с этим значением можно делать. В этом уроке три типа: `string` — текст в двойных кавычках, `int` — целое число, `bool` — `true` или `false`.

Кавычки меняют тип: `"12"` — текст из двух символов, `12` — число. Текст нельзя сложить с числом, а число нельзя вернуть там, где обещан текст: компилятор остановит программу и скажет об этом.

> **Важно.** У каждого типа есть нулевое значение, которое получает переменная без начального: `""` для string, `0` для int, `false` для bool.

## Переменная и константа

Переменная (variable) связывает имя со значением. Внутри функции `age := 27` объявляет имя и сама выводит тип из правой части. После этого `age = 28` меняет значение, а `age := 28` в том же блоке — ошибка «no new variables on left side of :=».

```go
package main

import "fmt"

func main() {
    name := "Алия"
    age := 27
    active := true
    fmt.Println(name, age, active)
    age = 28
    fmt.Println("через год:", age)
}
```

Вывод:

```text
Алия 27 true
через год: 28
```

Константа (constant) объявляется словом `const` и не меняется: `const currency = "₸"`. Если значение по смыслу постоянное — это константа; если приходит снаружи или меняется — переменная.

> **Типичная ошибка.** `age` и `Age` — разные имена: регистр важен. Ошибка `undefined: Age` почти всегда означает опечатку в имени.

## Склеить текст или отформатировать

Две строки склеиваются плюсом: `"Привет, " + name + "!"`. Для сложных фраз удобнее `fmt.Sprintf`: он собирает строку по шаблону и **возвращает** её, а не печатает. В шаблоне `%s` — место для строки, `%d` — для целого, `%t` — для bool.

```go
package main

import "fmt"

func main() {
    name := "Алия"
    price := 1250
    count := 2
    fmt.Println("Привет, " + name + "!")
    fmt.Println(fmt.Sprintf("Итого: %d %s", price*count, "₸"))
}
```

Вывод:

```text
Привет, Алия!
Итого: 2500 ₸
```

Аргументы подставляются по порядку маркеров; лишний аргумент или маркер не того типа даёт странный вывод вроде `%!d(string=…)`, хотя программа компилируется.

## Функция, которая возвращает текст

До сих пор `main` только печатала. В заданиях этого урока ты пишешь функцию, которая **возвращает** значение, а печатает его уже проверяющая среда:

```go
package main

import "fmt"

func greeting(name string) string {
    return "Привет, " + name + "!"
}

func main() {
    fmt.Println(greeting("Алия"))
}
```

Сигнатура `func greeting(name string) string` читается так: функция `greeting`, параметр `name` типа string, результат типа string. `return` отдаёт результат вызвавшему коду.

## Как проходят функциональные задания

В заданиях ниже у тебя нет `main`: среда сама вызывает твою функцию с несколькими входами и печатает каждый результат отдельной строкой в виде JSON. Поэтому строки показываются **в кавычках** — кавычки не часть значения. «Запустить» прогоняет открытые примеры и показывает их результаты; «Проверить» прогоняет ещё и закрытые примеры и показывает только галочки.

> **Важно.** Оставь `package main` из стартового кода, не добавляй `func main` и не печатай ничего сам. Импорты разрешены только те, что названы в карточке: лишний `import` отклоняется до запуска с сообщением «import … is not allowed».

## Если что-то пошло не так

- `no new variables on left side of :=` → имя уже объявлено; замени `:=` на `=`.
- `cannot use … (untyped string constant) as int value` → в кавычках текст, а ждали число, или наоборот.
- `undefined: имя` → опечатка или другой регистр.
- `import "fmt" is not allowed` → в этом задании импорты запрещены; собери строку плюсом.
- Результат показан как `"Привет, Алия!"` с кавычками → всё верно, так среда показывает строку.

## Практика

Во всех трёх заданиях сигнатура одна: `func formatGreeting(name string) string`. Меняется только то, что функция должна вернуть.

### Задание 1 · Данные участника

**Цель.** Вернуть строку `Привет, <имя>!` для переданного имени, без печати.

**Ожидаемый вывод** — «Запустить» подставит имена `Алия` и `Ada` и покажет:

```text
"Привет, Алия!"
"Привет, Ada!"
```

**Шаги.**
1. Выбери задание «Данные участника»: в редакторе — функция `formatGreeting`, которая пока возвращает `""`.
2. Замени `return ""` на возврат склеенной строки: `"Привет, "`, затем `name`, затем `"!"`.
3. Нажми «Запустить» и сравни обе строки с блоком выше: пробел после запятой, восклицательный знак.
4. Нажми «Проверить» — среда проверит ещё пустое имя и имя с пробелом.

**Как проверить себя.** После «Запустить» в «Результате» ровно две строки в кавычках, как в блоке выше. После «Проверить» — все галочки «пример 1…» и «закрытый пример …» зелёные.

**Если не принято.**
- «Проверь объявление функции…: import "fmt" is not allowed» → в этом задании импорты запрещены; используй `+`.
- Красный «пример 1» при похожем тексте → сравни пробел после запятой и знак `!`.
- Красный только «закрытый пример 1» → для пустого имени должно получиться `Привет, !` — не добавляй проверок на пустоту, задание их не требует.

> **Подсказка.** Нужна одна строка кода после `func …`: `return` и три части через `+`.

### Задание 2 · Фраза с форматированием

**Цель.** Та же фраза `Привет, <имя>!`, но собранная через `fmt.Sprintf` с маркером `%s`.

**Ожидаемый вывод** — для имён `Жанна` и `A B`:

```text
"Привет, Жанна!"
"Привет, A B!"
```

**Шаги.**
1. Выбери задание «Фраза с форматированием».
2. Добавь над функцией строку `import "fmt"` — здесь этот импорт разрешён.
3. Верни `fmt.Sprintf("Привет, %s!", name)`.
4. «Запустить», сравни. «Проверить».

**Как проверить себя.** Две строки как в блоке выше; при «Проверить» зелёные и закрытые примеры — среди них кириллица, пустое имя и имя с пробелом.

**Если не принято.**
- `undefined: fmt` → забыл `import "fmt"`.
- В результате `%!s(MISSING)` или лишние символы → маркер и аргумент не совпадают по числу или порядку.
- Результат без восклицательного знака → он должен стоять внутри шаблона после `%s`.

> **Подсказка.** `Sprintf` возвращает строку — её и нужно вернуть через `return`, а не печатать через `Println`.

### Задание 3 · Строка для чека

**Цель.** Вернуть `Покупатель: <имя>`, сохранив имя как есть, без печати.

**Ожидаемый вывод** — для `Алия Садыкова` и пустого имени:

```text
"Покупатель: Алия Садыкова"
"Покупатель: "
```

**Шаги.**
1. Выбери задание «Строка для чека».
2. Верни `"Покупатель: "` плюс `name`. Импорты здесь снова запрещены.
3. «Запустить»: вторая строка заканчивается пробелом после двоеточия — так и должно быть.
4. «Проверить».

**Как проверить себя.** Две строки как в блоке выше, включая `"Покупатель: "` с пробелом в конце; все галочки зелёные.

**Если не принято.**
- Красный «пример 2» → ты убрал пробел после двоеточия или добавил что-то для пустого имени.
- Красный закрытый пример → имя с пробелами внутри должно сохраниться без обрезки: не вызывай функции обработки текста.
- Отказ из-за импорта → удали `import`.

> **Подсказка.** Это задание на точность: ровно текст `Покупатель: ` с одним пробелом и ровно `name`.

## Итог

- Тип задаёт, что можно делать со значением: текст в кавычках, число без кавычек, bool — true/false.
- `:=` объявляет переменную и выводит тип, `=` меняет значение, `const` фиксирует его навсегда.
- Функция возвращает значение через `return`; в заданиях печатает за тебя среда, и строки показываются в кавычках.
