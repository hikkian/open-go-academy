# Значения, переменные и простые типы

## Зачем это нужно

Форма заказа содержит имя, количество и признак оплаты. Программа должна сохранить эти сведения, чтобы построить чек или принять решение. Мы продолжим [первый урок](lesson:zero-01): вместо печати готовой фразы начнём хранить данные с понятными именами и типами.

## Данные и типы

Компьютеру нужны не только команды, но и текущие данные. Значение — конкретная информация вроде `"Алия"`, `27` или `true`. Тип (type, тип данных) задаёт допустимый смысл значения и операции. Поэтому `"12"` — текстовая строка, а `12` — целое число: кавычки меняют тип. Базовые типы этой главы — `string`, `int`, `bool`. Их нулевые значения равны `""`, `0`, `false`.

Переменная (variable, переменная) связывает имя с текущим значением. Внутри функции `age := 27` объявляет имя, а `:=` просит компилятор вывести тип из правой части. Статическая типизация означает, что `age` остаётся целым типом и позднее нельзя записать туда строку. Явная форма `var age int = 27` показывает тип прямо. `var age int` без значения допустимо и получает нулевое значение. После объявления `age = 28` обновляет переменную; повторное `age := 28` в том же блоке не нужно, если новое имя не вводится. Имя чувствительно к регистру: `age` и `Age` разные. Выбирайте описательные имена, чтобы читать код без догадок.

Константа (constant, константа) создаётся `const` и не может быть изменена присваиванием. Используйте её для фиксированного правила или подписи. Если значение зависит от входа или меняется, это переменная. Необходимость указать конкретный тип определяется контекстом; не рассчитывайте, что строка и число будут автоматически смешаны.

Пакет `fmt` форматирует вывод. `Println` печатает и добавляет перевод строки; `Sprintf` строит строку и возвращает её. Формат `%s` ожидает строку, `%d` — целое, `%t` — bool. Это важно в упражнении, где функция возвращает фразу вызывающему коду. Сигнатура `func greeting(name string) string` читается так: имя функции, параметр `name` типа string, результат string. `return` передаёт результат назад, а `greeting("Алия")` вызывает функцию. Полная тема функций появится позднее; здесь нужен этот минимальный договор.

## Примеры

Сохраните каждый пример в `main.go`; `go run main.go` запускает его, как в [предыдущем уроке](lesson:zero-01).

```go
package main
import "fmt"
func main() {
 name := "Алия"; age := 27; active := true
 fmt.Printf("Имя: %s; возраст: %d; активен: %t\n", name, age, active)
}
```

Аргументы сопоставляются спецификаторам по порядку. `\n` завершает строку.

```go
package main
import "fmt"
func main() {
 const currency = "₸"; price := 1250; count := 2
 total := price * count
 fmt.Printf("Итого: %d %s\n", total, currency)
}
```

`total` — новое значение из двух целых. Учебный пример считает сумму в целых тенге, не вводя дробные деньги.

```go
package main
import "fmt"
func greeting(name string) string { return fmt.Sprintf("Привет, %s!", name) }
func main() { fmt.Println(greeting("Алия")) }
```

Функция возвращает текст, `main` его печатает. В функциональной карточке запуск вызывается платформой, поэтому собственного `main` там нет.

## Ошибки и диагностика

`no new variables on left side of :=` обычно означает повторное объявление: замените оператор на `=`. Несовместимые типы требуют выяснить, является ли значение числом или текстом, а не маскировать проблему. `undefined` означает опечатку, иной регистр или недоступную область видимости. Если вывод неверен, проверьте каждый маркер `%` и его аргумент. Изменение `const` — ошибка компиляции по определению. Читайте первое сообщение компилятора и сравнивайте ожидаемый и фактический типы.


В начале каждой карточки есть сигнатура — короткое описание имени функции, её входов и результата. Например, `func f(n int) string` означает: функция `f` принимает целое `n` и возвращает строку. Среда сама подставляет входные данные, вызывает функцию и выводит каждый результат как JSON-текст; строковый результат виден в кавычках JSON. Это представление результата, а не команда печати. Сохраните строку `package main` из стартового кода. Не добавляйте `func main`: запускающую функцию предоставляет проверяющая среда. Эталонное решение лежит отдельно и показывается существующим действием раскрытия.

## Практика

### Easy — Данные участника

Верните строку `Привет, <имя>!` для переданного имени. Не печатайте её. Проверяются обычное, составное и пустое имя.

### Medium — Фраза с форматированием

Сигнатура прежняя; соберите `Привет, <имя>!` через fmt.Sprintf с корректным %s. Импорт fmt разрешён. Проверяются кириллица и пустое имя.

### Hard — Строка для чека

Верните `Покупатель: <имя>`, сохранив вход как есть. Не обрезайте пробелы и не печатайте. Проверяются пустое и составное имя.


## Как читать объявление и выбирать модель данных

Можно разобрать `var name string = "Алия"` на четыре части: `var` говорит, что создаётся переменная; `name` — её локальное имя; `string` — тип; выражение после `=` задаёт начальное значение. В коротком `name := "Алия"` тип не исчезает, а выводится компилятором. Оба способа создают типизированное имя. Оператор `:=` можно применять внутри функции; на уровне пакета переменные объявляют формой `var`. В наших законченных программах присваивание происходит внутри `main`, поэтому короткая форма подходит.

Выбор типа начинается не с того, «что удобнее напечатать», а с вопроса «что это значит?». Количество людей — целое, метка состояния — строка или bool, а произвольное имя — строка. Не кодируйте состояние словами `"да"` и `"нет"`, если логика должна проверять истину: тип bool сообщает намерение точнее. Не храните число в кавычках, если над ним предстоит арифметика. В обратном случае идентификатор заказа вроде `"0012"` может быть именно текстом, потому что начальные нули имеют смысл. Контекст определяет модель данных.

Присваивание вычисляет правую часть до замены значения. В `count = count + 1` старая величина читается справа, затем новое число связывается с тем же именем слева. Это не математическое равенство, а команда обновления. Если переменная содержит итог, можно сделать обновление компактным `count++` или `count += 1`; не следует использовать такую краткость, если она затрудняет понимание новичку.

## Формат — отдельный слой

Внутреннее значение и его текстовое отображение — не одно и то же. `age` остаётся `int`, даже если `Printf` показывает цифры. `Sprintf` создаёт строку для интерфейса, но не меняет исходные переменные. Поэтому сначала вычислите смысловые значения, затем формируйте подпись. Например, общая цена может быть `int`, а чек — `string`, собранный из неё и знака валюты. Такое разделение помогает позднее менять вид чека, не переписывая вычисление.

Форматная строка — инструкция `fmt`, где `%d` заменяется представлением целого значения. Каждый спецификатор сопоставляется аргументу по позиции. Лишний аргумент или несовпадающий тип может привести к диагностике форматирования в момент запуска, даже если сама программа компилируется. Поэтому проверяйте дважды: количество маркеров и фактические типы аргументов. Для простых учебных сообщений `Println` часто проще, но если требуется точная пунктуация и структура, `Sprintf` нагляден.

## Способы самостоятельной проверки

При чтении чужой строки кода называйте вслух каждую часть: «объявили имя, тип вывели, справа текст». Затем предскажите значение выражения до запуска. Это тренирует чтение, а не только механическое копирование. Для проверки типов временно передайте строку туда, где ожидается число: компилятор остановит программу и укажет несовместимость. Верните исходный тип сразу после наблюдения. Не оставляйте намеренно сломанный пример как финальный ответ.

Упражнения используют одинаковую сигнатуру, чтобы сосредоточиться на данных и контракте. В Easy сначала возвращается конкатенация литералов и параметра. В Medium явно тренируется шаблон `%s`. В Hard спецификация меняет только текстовый шаблон; код должен точно сохранить вход. Рост сложности здесь в точности соблюдения требований, а не в новой синтаксической конструкции. Именно такой переход от малого изменения к надёжному контракту помогает учиться без AI.



Если непонятно, какое объявление выбрать, начните с явного `var имя тип`, убедитесь, что пример понятен, а затем сократите его до `:=`, если это улучшает чтение. Понятность важнее минимального числа символов. После присваивания спросите себя: может ли это значение реально измениться? Если нет по смыслу и правилу, возможно, нужна константа. Если оно поступило от пользователя, обычно это переменная.

## Повторение и итог

Вернитесь к каждой ключевой идее через день и объясните её своими словами. Напишите минимальный пример без копирования, предскажите результат до запуска и затем проверьте программу. Если ответ отличается, установите конкретный шаг расхождения. Следующий урок опирается на это умение и продолжает путь курса без обязательных внешних материалов.

## Мини-глоссарий

**value** — значение, **type** — тип, **variable** — переменная, **constant** — константа, **string** — строка, **integer** — целое число, **boolean** — логическое значение, **declaration** — объявление
