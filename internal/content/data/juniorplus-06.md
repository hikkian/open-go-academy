# Маршруты, методы и redirects

## Что ты сделаешь

Ты напишешь три маршрутизатора: `NewHealthRouter` отвечает на проверку здоровья, `NewShortRedirectHandler` перенаправляет короткие ссылки на известные адреса, `NewSafeRedirectHandler` перенаправляет только на локальный путь. Все три возвращают ответы, которые проверяются без сети.

## Маршрут, метод и ресурс — разные причины отказа

Запрос может не найти путь (404), найти путь, но не тот метод (405), или найти всё, но не найти запись. Это три разные ситуации, и клиент по ним действует по-разному: 404 значит «такого адреса нет», 405 значит «адрес есть, но этот метод не разрешён». Поэтому 405 всегда сопровождается заголовком `Allow`, который называет разрешённые методы:

```go
package main

import (
    "fmt"
    "net/http"
)

func main() {
    fmt.Println(http.StatusNoContent, http.StatusFound, http.StatusMethodNotAllowed)
}
```

Вывод: `204 302 405`. Константы статусов из `net/http` читаются лучше чисел: `http.StatusFound` и есть 302.

> **Важно.** Статус 405 без заголовка `Allow` нарушает контракт HTTP: клиент не знает, какие методы допустимы.

## Перенаправление: статус 302 и Location

Перенаправление отвечает статусом 3xx и заголовком `Location` с новым адресом. Клиент сам выполнит второй запрос:

```go
package main

import (
    "fmt"
    "net/http"
    "net/http/httptest"
)

func main() {
    h := func(w http.ResponseWriter, r *http.Request) {
        w.Header().Set("Content-Type", "text/html; charset=utf-8")
        w.Header().Set("Location", "/articles/go")
        w.WriteHeader(http.StatusFound)
    }
    rec := httptest.NewRecorder()
    h(rec, httptest.NewRequest(http.MethodGet, "/go/go", nil))
    fmt.Println(rec.Code, rec.Header().Get("Location"))
}
```

Вывод: `302 /articles/go`. Заголовок `Location` задан до статуса, как и все заголовки.

> **Типичная ошибка.** Передавать в `Location` значение из запроса без проверки. Так злоумышленник получает открытый редирект: ссылка с вашего сайта ведёт на чужой адрес.

## Открытый redirect: локальный путь или ничего

Цель перехода безопасна, если это путь внутри сайта: без схемы, без хоста, без `//` в начале. `url.Parse` разбирает строку, и по полям `Scheme` и `Host` видно, внешняя ли это цель:

```go
package main

import (
    "fmt"
    "net/url"
)

func main() {
    for _, t := range []string{"/articles/go", "https://evil.example"} {
        u, err := url.Parse(t)
        fmt.Println(err == nil && u.Scheme == "" && u.Host == "")
    }
}
```

Вывод: `true` и `false`. Локальный путь проходит, внешняя ссылка — нет.

## Если что-то пошло не так

- `undefined: url` → импорт `"net/url"` не добавлен.
- Редирект возвращает 200 → статус не задан: `WriteHeader(http.StatusFound)`.
- Для `/go/go/extra` выходит перенаправление → код брался из префикса без проверки остатка пути.
- `imported and not used: net/url` → импорт есть, а разбор цели не выполнен.

### Задание 1 · Задай health маршрут

**Цель.** `GET /health` отвечает 204 без тела. Другой метод на этом пути — 405 с `Allow: GET`. Неизвестный путь — 404.

**Ожидаемый вывод** — запросы `GET /health` и `POST /health`:

```text
{"Status":204,"Body":"","ContentType":"","Location":"","Allow":""}
{"Status":405,"Body":"method not allowed\n","ContentType":"text/plain; charset=utf-8","Location":"","Allow":"GET"}
```

**Шаги.**
1. Выбери задание «Задай health маршрут»: в файле есть `NewHealthRouter` с `panic("TODO")`. Импорт `"net/http"` уже есть.
2. Создай маршрутизатор `mux := http.NewServeMux()`.
3. Зарегистрируй путь `/health`: если метод `GET`, ответь `w.WriteHeader(http.StatusNoContent)`, не задавая `Content-Type`.
4. Для других методов задай `Allow: GET` и ответь через `http.Error` со статусом 405.
5. Верни `mux`, нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два объекта ответа; все три критерия зелёные.

**Если не принято.**
- Для `GET` выходит 200 с телом → нужен именно статус 204 без тела.
- Для `DELETE` вышло 204 → проверка метода должна стоять до ответа.
- Путь `/health/` даёт 405 → такой путь не зарегистрирован, ответ должен быть 404.

> **Подсказка.** Проверка метода — первая строка обработчика, а ответ 204 занимает одну строку.

### Задание 2 · Перенаправь известный short code

**Цель.** `GET /go/go` и `GET /go/http` отвечают 302 с `Location` на `/articles/go` и `/guide/http`. Неизвестный код или вложенный путь — 404. Другой метод на коротком адресе — 405 с `Allow: GET`.

**Ожидаемый вывод** — запросы `GET /go/go` и `GET /go/http`:

```text
{"Status":302,"Body":"","ContentType":"text/html; charset=utf-8","Location":"/articles/go","Allow":""}
{"Status":302,"Body":"","ContentType":"text/html; charset=utf-8","Location":"/guide/http","Allow":""}
```

**Шаги.**
1. Выбери задание «Перенаправь известный short code»: в файле есть `NewShortRedirectHandler` с `panic("TODO")`.
2. Создай маршрутизатор и зарегистрируй префикс `/go/`.
3. Если метод не `GET`, задай `Allow: GET` и ответь 405.
4. Возьми код как остаток пути: `r.URL.Path[len("/go/"):]`.
5. Для `go` и `http` задай `Content-Type: text/html; charset=utf-8`, `Location` с адресом из таблицы и статус 302 через `WriteHeader`.
6. Для любого другого кода ответь через `http.NotFound`.
7. Нажми «Запустить» и сравни с блоком выше.
8. Нажми «Проверить».

**Как проверить себя.** Два ответа 302 с правильными `Location`; все три критерия зелёные.

**Если не принято.**
- `/go/go/extra` перенаправлен → код должен быть точным остатком пути без вложенности.
- Для `POST /go/go` вышло 302 → проверка метода должна стоять первой.
- Неизвестный код даёт 200 → для него нужен ответ 404.

> **Подсказка.** Таблица из двух записей: код и адрес. Всё, что не в таблице, — 404.

### Задание 3 · Запрети open redirect

**Цель.** `GET /go` перенаправляет на адрес `target`, если он локальный путь: начинается с `/`, не с `//`, без схемы и хоста, без обратной косой черты. Иначе — 400 с текстом `invalid redirect target`. Другой метод — 405, неизвестный путь — 404.

**Ожидаемый вывод** — цели `/articles/go` и `/guide/http`, для каждой запрос `GET /go`:

```text
{"Status":302,"Body":"","ContentType":"text/html; charset=utf-8","Location":"/articles/go","Allow":""}
{"Status":302,"Body":"","ContentType":"text/html; charset=utf-8","Location":"/guide/http","Allow":""}
```

**Шаги.**
1. Выбери задание «Запрети open redirect»: в файле есть `NewSafeRedirectHandler` с `panic("TODO")`. Добавь импорты `"net/url"` и `"strings"`, если используешь.
2. Создай маршрутизатор и зарегистрируй `/go`.
3. Если метод не `GET`, задай `Allow: GET` и ответь 405.
4. Проверь цель `target`: разбор через `url.Parse`, пустой `Scheme` и `Host`, начало с `/`, отсутствие `//` в начале и `\` внутри.
5. Если проверка не прошла, ответь 400 через `http.Error` с текстом `invalid redirect target`.
6. Иначе задай `Content-Type`, `Location` и статус 302.
7. Нажми «Запустить» и сравни с блоком выше.
8. Нажми «Проверить».

**Как проверить себя.** Два ответа 302 с локальными `Location`; все три критерия зелёные.

**Если не принято.**
- Цель `//evil.example` принята → проверка `//` в начале должна давать 400.
- Цель `https://evil.example` принята → разбор через `url.Parse` и проверка `Scheme` и `Host`.
- Для `POST /go` вышло 302 → метод проверяется до перенаправления.

> **Подсказка.** Сначала проверка формы цели, потом только ответ 302.
