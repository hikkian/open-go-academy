# Редактор, Go и диагностика

## Где писать программу

Редактор — приложение для изменения текста файлов. Уроки Open Go Academy можно полностью проходить в браузере: код пишется в учебном редакторе и исполняется кнопкой Run. Локальная установка Go не требуется. Этот вариант полезен, если вы пока не хотите менять настройки компьютера или изучаете тему с телефона.

Файл — сохранённый текст, а папка (directory, каталог) группирует файлы. Имя `main.go` принято для примера, но компилятору важны корректное содержимое и выбранные файлы. Путь (path) указывает расположение: `lessons/hello/main.go` означает файл `main.go` внутри `hello`, который внутри `lessons`. Полный путь начинается от корня диска или файловой системы; относительный путь отсчитывается от текущей папки.

Текущая папка (working directory, рабочая директория) — место, от которого команда ищет относительные пути. Если команда сообщает, что `main.go` отсутствует, это может означать неверную текущую папку, опечатку или несохранённый файл. Это сообщение не доказывает, что программа Go написана неправильно: инструмент ещё не нашёл файл, чтобы прочитать его.

## Инструментарий Go

Инструментарий (toolchain, цепочка инструментов) — программы, которые помогают форматировать, проверять, собирать и запускать исходный код. Установленный Go предоставляет команду `go`; браузерная площадка предоставляет аналогичные действия через свои кнопки.

В локальном терминале обычно используют:

```sh
go version
go fmt main.go
go run main.go
```

`go version` показывает доступный инструмент; `go fmt` форматирует исходный код по принятому стилю; `go run` проверяет, собирает и запускает программу. Вводите команды только если сами установили Go и понимаете, в какой папке находитесь. Эти команды читают и форматируют учебный файл, а `go run` исполняет саму программу. Не копируйте в терминал случайные команды из интернета.

```go
package main

import "fmt"

func square(value int) int {
    return value * value
}

func main() {
    fmt.Println(square(5))
}
```

Это законченный безопасный пример без чтения файлов и сетевых подключений. Сохраните его как `main.go`. В браузере нажмите Run; при установленном локальном Go можно выполнить `go run main.go` из папки с файлом. Результат — `25`.

## Форматирование

Форматирование — единообразное расположение пробелов и фигурных скобок, которое облегчает чтение. `gofmt` — форматтер, который поставляется с Go; команда `go fmt` запускает его для Go-файлов пакета. Форматтер не исправляет неправильный алгоритм и не угадывает намерение. Если пропущена скобка, сначала нужно исправить синтаксис, после чего форматирование возможно.

В браузерном редакторе обычно достаточно использовать встроенную команду форматирования. Не нужно вручную выравнивать каждую строку пробелами. Go намеренно задаёт общий стиль, чтобы код разных авторов выглядел похоже.

## Этапы и виды сообщений

Сначала инструмент находит исходный файл. Затем анализирует синтаксис — допустимую форму кода; проверяет типы и имена; после этого собирает программу и запускает её. Сообщение `undefined: square` указывает, что имя не найдено в области видимости. `syntax error` говорит о недопустимой структуре: часто забыта скобка, кавычка или слово. Ошибка типа появляется, когда значение не подходит ожидаемому типу. Эти формулировки зависят от контекста, поэтому смотрите на имя файла и номер строки.

```text
main.go:8:14: undefined: squre
```

Это учебный пример формата диагностики, не результат запуска команды на вашем устройстве. Файл указан первым, затем строка и позиция; слово `squre` похоже на опечатку имени `square`. Исправьте имя в указанной строке и снова запустите программу. Если строка указывает на закрывающую скобку, причина может находиться чуть выше — например пропущена открывающая.

```text
main.go:5:1: syntax error: unexpected EOF
```

EOF означает конец файла. Сообщение подсказывает, что парсер дошёл до конца, пока ожидал продолжение конструкции. Проверьте парные `{}` и `()` сверху вниз. Не переписывайте файл целиком: исправляйте одно предположение за раз.

```text
main.go:4:9: cannot use "5" as int value
```

Текст `"5"` и число `5` — разные значения. Если функция обещает вернуть `int`, в `return` должно находиться целое число. Читайте диагностику как подсказку о конфликте типов, а не как оценку ваших способностей.

## Безопасный порядок диагностики

Сделайте четыре спокойные проверки: прочитайте первое сообщение; сверьте путь и имя файла; перейдите к указанной строке; исправьте одну причину и запустите снова. Ошибки ниже в списке могут исчезнуть автоматически после устранения первой. Перед повторным запуском сохраните изменения, если редактор не сохраняет их автоматически.

Упражнения этого урока классифицируют фиксированный текст и предлагают следующий безопасный шаг. Они не запускают команды операционной системы и не читают файлы ученика. Никогда не вставляйте пароль или секретный ключ в исходник, сообщение ошибки или учебный чат.

## Необязательная локальная установка

Официальная инструкция Go доступна по адресу [go.dev/doc/install](https://go.dev/doc/install). Установка — необязательный отдельный путь; браузерного редактора достаточно для всех упражнений курса. Версия, указанная в карточке урока, обозначает учебную базовую версию репозитория, а не требование установить её для прохождения.

Если вы добровольно устанавливаете Go, следуйте официальной странице для своей операционной системы и используйте обычные системные настройки и установщик. Не отключайте защиту системы, не запускайте команды с повышенными правами и не удаляйте папки ради исправления неизвестной ошибки. После установки откройте новый терминал и проверьте `go version`. Если команда не найдена, сначала перезапустите терминал и перечитайте официальные шаги проверки пути. Вы всегда можете вернуться к браузерной среде.

## Привычки редактора

Сначала убедитесь, что открыли правильное упражнение и файл `main.go`. Внесите небольшое изменение, нажмите Run и прочитайте полный вывод. После успешного результата сравните его с ожидаемым; затем измените вход или ветку, чтобы проверить понимание. Сохранение и отправка на проверку — разные действия: сохранённый черновик можно продолжить позже, а Submit запускает критерии упражнения.

Распространённые ошибки: запускать команду в неверной папке; искать проблему в Go, когда файл не сохранён; исправлять последнюю строку сообщения вместо первой; вручную переименовывать функцию и тем самым нарушать заданную сигнатуру; принимать форматирование за проверку правильности. Отделяйте этап поиска файла, этап компиляции и поведение уже запущенной программы.

## Практика

### Простое — `classifyDiagnostic`

Получив одну фиксированную диагностическую строку, верни короткую категорию по контракту упражнения: отсутствующая команда, отсутствующий файл или ошибка исходного кода. Условие явно задаёт распознаваемые фрагменты. Не вызывай ОС и не пытайся исправить компьютер.

### Среднее — `nextSafeStep`

Для учебной диагностики выбери первый безопасный следующий шаг: проверить папку/имя файла, проверить скобки и кавычки либо прочитать строку ошибки. Не предлагай команды с правами администратора или удаление файлов.

### Сложное — `explainDiagnostic`

По паре «текст сообщения + этап» верни объяснение из небольшого фиксированного набора. Контракт включает все категории во входных примерах. Это упражнение моделирует объяснение ошибки, а не выполняет неизвестный код.

## Самопроверка

Ответьте: чем путь отличается от текущей папки; что делает `go fmt`; в каком порядке искать источник ошибки; почему `stat main.go` не говорит о синтаксисе файла; почему локальная установка необязательна; какое безопасное действие следует предпринять, если не понимаете случайную команду.

## Итог

Вы умеете различать файл, путь и текущую папку, знаете назначение базовых команд Go и можете читать учебную диагностику по этапам. Локальная установка остаётся добровольной, а упражнения не воздействуют на файловую систему. Следующая глава применит функции к массивам и срезам.

## Разбор сообщения по частям

Диагностика часто имеет форму `файл:строка:позиция: причина`. Например, `main.go:8:14: undefined: squre` сообщает файл, строку, позицию и проблему с именем. Не каждое сообщение имеет одинаковый формат: операционная система, редактор и компилятор могут писать по-разному. Поэтому распознавайте смысл и этап, а не заучивайте пунктуацию.

Если программа завершилась ошибкой во время выполнения, компиляция уже прошла. Посмотрите на вход и операцию: возможно, индекс вышел за границу или значение пустое. Не нужно переустанавливать Go из-за ошибки логики в учебной функции. Установка помогает, если отсутствует инструмент и вы выбрали локальную работу.

Путь `lessons/hello/main.go` зависит от текущей папки. Из каталога проекта он может существовать, а из другой папки — нет. Полный путь устраняет эту зависимость, но новичку проще открыть проект и работать из его папки. В браузере папка упражнения выбирается интерфейсом.

Короткий журнал диагностики звучит так: «увидел no such file, проверил сохранение и папку, нашёл опечатку в имени». Он помогает другому человеку воспроизвести проблему. Не включайте в него пароли, приватные ключи и содержимое личных файлов.

Если решите установить Go, используйте официальную инструкцию и выбирайте шаги для своей системы. Если инструкция непонятна или устройство учебное/чужое, остановитесь и продолжайте в браузере: установка не является условием курса.
