# Вычисления и ветвления

## Что ты сделаешь

Ты напишешь функцию `classify`, которая по числу возвращает слово: сначала знак числа, потом три погодных категории, потом четыре с точными границами. Для этого разберёмся, как Go считает, сравнивает и выбирает одну ветвь из нескольких.

## Выражения и арифметика

Выражение (expression) вычисляется в значение: `2 + 3` даёт `5`. Для целых чисел работают `+ - * / %`. Деление целых отбрасывает дробную часть: `7 / 2` равно `3`, а остаток даёт `%`: `7 % 2` равно `1`. Умножение и деление выполняются раньше сложения; скобки меняют порядок и делают замысел видимым.

```go
package main

import "fmt"

func main() {
    fmt.Println(7/2, 7%2)
    fmt.Println(2+3*4, (2+3)*4)
}
```

Вывод:

```text
3 1
14 20
```

> **Важно.** Делить на ноль нельзя: программа аварийно остановится. Если делитель может быть нулём, сначала проверь его условием.

## Сравнения и логика

Сравнение возвращает bool: `n < 0`, `n == 0`, `n != 0`. Один знак `=` — присваивание, два `==` — проверка равенства. Условия соединяются: `&&` — «и» (нужны обе части), `||` — «или» (хватит одной), `!` — «не».

```go
package main

import "fmt"

func main() {
    age := 21
    hasTicket := true
    fmt.Println(age >= 18, age >= 18 && hasTicket, age < 18 || hasTicket)
}
```

Вывод:

```text
true true true
```

Go вычисляет `A && B` лениво: если `A` ложно, `B` даже не проверяется. Поэтому безопасную проверку ставят слева: `denominator != 0 && total/denominator > 1`.

> **Типичная ошибка.** `if n = 0` вместо `if n == 0`: ты пытаешься присвоить, а не сравнить, и компилятор это отклонит.

## Ветвление if

`if условие { … } else if условие { … } else { … }` выбирает одну ветвь. Скобки вокруг условия не нужны, фигурные скобки обязательны. Проверки идут сверху вниз, и после первой истинной остальные пропускаются — поэтому во второй ветви не надо повторять отрицание первой.

```go
package main

import "fmt"

func weather(t int) string {
    if t < 0 {
        return "Мороз"
    } else if t < 20 {
        return "Прохладно"
    }
    return "Тепло"
}

func main() {
    fmt.Println(weather(-2), weather(0), weather(19), weather(20))
}
```

Вывод:

```text
Мороз Прохладно Прохладно Тепло
```

Ветвь `t < 20` достижима только когда `t < 0` ложно, то есть означает «от 0 до 19». `return` внутри ветви сразу завершает функцию, поэтому последний `return` не нуждается в `else`.

## Границы: где чаще всего ошибка

Перед кодом выпиши диапазоны словами и проверь, что они не пересекаются и не оставляют дырок: «ниже 0», «от 0 до 19 включительно», «от 20». Для каждой границы L проверь три числа: L−1, L, L+1. Для границы 20 это 19, 20, 21. Закрытые примеры заданий устроены именно так.

> **Зачем.** Ошибка на единицу (`<` вместо `<=`) компилируется и проходит обычные примеры; её ловят только граничные значения.

## Если что-то пошло не так

- `syntax error: unexpected =` в условии → нужно `==`.
- `missing return` → не все пути функции возвращают значение; добавь последний `return` без условия.
- Красный только «закрытый пример» при зелёных открытых → проверь границу: `<` или `<=`.
- `non-boolean condition in if statement` → в условии число, а нужно сравнение.
- `import … is not allowed` → в заданиях урока импорты запрещены; `fmt` здесь не нужен.

## Практика

Сигнатура во всех заданиях одна: `func classify(n int) string`. Среда вызывает функцию с разными `n` и показывает результаты строками в кавычках; `main` и печать не нужны.

### Задание 1 · Знак числа

**Цель.** Вернуть `ниже нуля`, `ноль` или `выше нуля` в зависимости от знака `n`.

**Ожидаемый вывод** — для `n` = −1, 0, 1:

```text
"ниже нуля"
"ноль"
"выше нуля"
```

**Шаги.**
1. Выбери задание «Знак числа»: в редакторе `classify`, которая пока возвращает `""`.
2. Первая ветвь: если `n < 0`, верни `"ниже нуля"`.
3. Вторая: если `n == 0`, верни `"ноль"`.
4. Последней строкой верни `"выше нуля"` без условия.
5. «Запустить», сравни три строки. «Проверить» — среда подставит ещё −100, 19, 20, 21, 35, 100.

**Как проверить себя.** Три строки как в блоке выше; все галочки, включая закрытые примеры, зелёные.

**Если не принято.**
- `missing return` → нет последнего `return`.
- Красный «пример 2» → для нуля вернулось не `ноль`: проверь `==`.
- Красный закрытый пример → положительные числа больше 1 тоже «выше нуля»: не ставь верхних ограничений.

> **Подсказка.** Три `return` — по одному на слово; условий нужно только два.

### Задание 2 · Погода

**Цель.** Вернуть `мороз` ниже 0, `прохладно` от 0 до 19, `тепло` от 20.

**Ожидаемый вывод** — для `n` = −1, 0, 20:

```text
"мороз"
"прохладно"
"тепло"
```

**Шаги.**
1. Выбери задание «Погода».
2. Выпиши границы: ниже 0 → мороз; 0…19 → прохладно; 20 и выше → тепло.
3. Напиши `if n < 0`, затем `if n < 20`, затем последний `return`.
4. «Запустить», сравни. «Проверить» — закрытые примеры включают 19, 20 и 21.

**Как проверить себя.** Три строки как в блоке выше; зелёные закрытые примеры означают, что граница 20 поставлена верно.

**Если не принято.**
- Красный закрытый пример при зелёных открытых → 19 должно быть «прохладно», 20 — «тепло»: проверь `<` против `<=`.
- Для −1 вернулось «прохладно» → ветвь `n < 0` стоит после `n < 20`; порядок важен.

> **Подсказка.** Вторая ветвь не должна повторять первую: `n < 20` уже означает «от 0 до 19», потому что отрицательные ушли в первую.

### Задание 3 · Предупреждение о жаре

**Цель.** Четыре категории: `мороз` ниже 0, `норма` 0…19, `тепло` 20…34, `жара` от 35.

**Ожидаемый вывод** — для `n` = −1, 0, 34, 35:

```text
"мороз"
"норма"
"тепло"
"жара"
```

**Шаги.**
1. Выбери задание «Предупреждение о жаре».
2. Выпиши четыре диапазона и три границы: 0, 20, 35. Для каждой границы — числа слева и справа.
3. Три `if` по возрастанию (`< 0`, `< 20`, `< 35`) и последний `return "жара"`.
4. «Запустить»: 34 должно дать «тепло», 35 — «жара». «Проверить».

**Как проверить себя.** Четыре строки как в блоке выше; закрытые примеры зелёные (там 19, 20, 21, 35, 100).

**Если не принято.**
- Красный «пример 3» или «пример 4» → граница 35: 34 — ещё «тепло», 35 — уже «жара».
- Красный закрытый пример при зелёных открытых → граница 20 (19 — «норма», 20 — «тепло»).
- `missing return` → нет последнего `return`.

> **Подсказка.** Каждое целое число должно попасть ровно в одну категорию: если ветви идут по возрастанию границ, дырок и пересечений не будет.

## Итог

- Арифметика целых отбрасывает дробь; `%` даёт остаток; на ноль делить нельзя.
- Сравнение возвращает bool; `&&`, `||`, `!` соединяют условия; `==` сравнивает, `=` присваивает.
- Цепочка `if / else if` выбирает первую истинную ветвь; границы проверяй числами L−1, L, L+1.
