# Что такое компьютер, программа и Go

## Что ты сделаешь

За этот урок ты напишешь и запустишь три маленькие программы на Go прямо в браузере: первая печатает одну строку, вторую нужно починить, третья печатает две строки. По дороге разберёмся, что происходит между нажатием «Запустить» и строкой в окне «Результат».

## Как устроен урок

Слева — текст и карточки заданий, справа — редактор с файлом `main.go`. Три кнопки: «Запустить» выполняет программу и показывает её вывод, «Проверить» сравнивает вывод с ожидаемым и сохраняет результат, «Сбросить код» возвращает стартовый файл. Список заданий — в разделе «Практика» внизу левой панели; выбери задание, и справа появится его файл.

> **Важно.** Проверка сравнивает вывод буква в букву. «Привет, Go!» и «Go готов!» — разные строки; принята будет только та, что стоит в блоке «Ожидаемый вывод» карточки.

## Компьютер: данные и команды

Компьютер не понимает намерений. Он выполняет очень простые команды, записанные заранее в точном порядке, и хранит данные, с которыми работает. Процессор (CPU) выполняет команды, память держит текущие данные, накопитель сохраняет файлы после выключения.

Данные внутри — биты, 0 и 1. Восемь бит — байт. Один и тот же набор байтов может быть числом, буквой или командой: смысл задаёт формат. Для нас это значит одно: программа — тоже текст в файле, пока её не запустили.

## Файл, папка, программа

Файл — именованный набор данных: `main.go` содержит текст программы на Go, `.txt` — просто текст. Папка группирует файлы; путь `course/day1/main.go` говорит, где файл лежит. Операционная система (operating system, OS) — Windows, macOS, Linux — управляет устройствами и даёт программам общие услуги: открыть файл, вывести текст, запустить другую программу.

В этом курсе файл лежит в браузере, а запускает его песочница на твоём компьютере. Терминал и установка Go на свою машину не нужны; если захочешь — [официальная инструкция Go](https://go.dev/doc/install), команда `go run main.go` в папке с файлом.

## Из текста в работающую программу

Исходный код (source code) — текст, который написал человек. Компилятор (compiler) проверяет, что текст соблюдает правила языка, и переводит его в команды процессора. Если правила нарушены, компилятор останавливается и сообщает, где и что не так; программа не запускается.

```text
main.go (текст) → компилятор Go → исполняемый код → процессор выполняет → вывод в «Результате»
```

Три разные вещи: файл с текстом, компилятор как инструмент, работающая программа (process). Когда «Результат» пуст и красный — сломался первый или второй шаг; когда вывод есть, но не тот — программа работает, но делает не то.

## Первая программа Go

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет, Go!")
}
```

Запусти её мысленно построчно:

- `package main` — программа начинается с пакета `main`. Пакет (package) — группа объявлений Go.
- `import "fmt"` — подключаем стандартный пакет `fmt` (format), в нём живёт печать текста.
- `func main() { ... }` — функция (function) `main`: именованный блок команд, с него начинается выполнение.
- `fmt.Println("Привет, Go!")` — вызываем `Println` из `fmt`; в скобках — что напечатать. Кавычки говорят: это текст. `Println` печатает его и переводит строку.
- `{` и `}` ограничивают тело функции; отступы — для глаз, Go сам их выравнивает кнопкой «Форматировать».

Вывод такой программы:

```text
Привет, Go!
```

> **Типичная ошибка.** `Println` и `println` — разные имена. Компилятор различает большие и маленькие буквы везде: в именах функций, пакетов, переменных.

## Число или текст?

`"42"` в кавычках — текст (string) из двух символов. `42` без кавычек — целое число (int). Компилятор никогда не подменяет одно другим: функция, обещавшая вернуть число, обязана вернуть число.

Функция может не только печатать, но и возвращать результат:

```go
package main

import "fmt"

func answer() int {
    return 7
}

func main() {
    fmt.Println(answer())
}
```

`func answer() int` — функция без входных значений, с результатом типа `int`; `return 7` отдаёт число тому, кто её вызвал. В `fmt.Println(answer())` скобки после имени — это вызов: сначала получаем `7`, потом печатаем. Так устроено задание [«Почини сломанную программу»](exercise:repair).

> **Типичная ошибка.** `fmt.Println(answer)` без скобок компилируется, но печатает не число, а адрес функции вроде `0x47e020`: ты передал саму функцию, а не её результат.

## Если что-то пошло не так

Читай первое сообщение в «Результате» — остальные часто следствие первого.

- `undefined: fmt` → нет строки `import "fmt"`.
- `syntax error` с номером строки → незакрытая скобка или кавычка; часто на строку раньше, чем указано.
- `cannot use "42" ... as int value` → в кавычках текст, а ждали число: убери кавычки.
- `declared and not used` → ты объявил имя и не использовал; удали или используй.
- Программа напечатала не то → сравни с «Ожидаемым выводом» по символам: пробелы, регистр, знаки препинания, количество строк.

## Практика

Три задания. В каждом — цель, точный ожидаемый вывод и шаги. Эталонное решение открывается кнопкой под редактором, но сначала попробуй сам.

### Задание 1 · Поздоровайся с компьютером

**Цель.** Напечатать ровно одну строку: `Go готов!`

**Ожидаемый вывод** — ровно так, с переводом строки в конце:

```text
Go готов!
```

**Шаги.**
1. Выбери задание «Поздоровайся с компьютером» в списке «Практика»: справа откроется `main.go` с пустой `func main()`.
2. Внутри фигурных скобок напиши вызов `fmt.Println` и передай ему текст `Go готов!` в двойных кавычках.
3. Нажми «Запустить» и сравни вывод с блоком выше: буква в букву, включая восклицательный знак.
4. Нажми «Проверить».

**Как проверить себя.** В «Результате» одна строка `Go готов!`, все четыре галочки зелёные, статус «Принято», и появляется сообщение «Задание принято. Прогресс обновлён».

**Если не принято.**
- Напечатал «Привет, Go!» или другой текст → красная «Публичный пример вывода»: текст в кавычках должен быть именно `Go готов!`.
- Красная «Точная проверка строк…», хотя текст похож → лишний пробел, вторая строка или другой регистр.
- Красный «Результат» с `undefined` или `syntax error` → смотри раздел «Если что-то пошло не так».

> **Подсказка.** Вызов печати выглядит так же, как в примере с «Привет, Go!» — меняется только текст между кавычками.

### Задание 2 · Почини сломанную программу

**Цель.** Сделать так, чтобы программа компилировалась и печатала число `42`, не убирая функцию `answer`.

**Ожидаемый вывод** — ровно так:

```text
42
```

**Шаги.**
1. Выбери задание «Почини сломанную программу» и нажми «Запустить», не меняя код: прочитай сообщение компилятора.
2. Первая поломка: `answer` обещает вернуть `int`, а возвращает текст `"42"`. Убери кавычки.
3. Снова «Запустить». Программа работает, но печатает что-то вроде `0x47e020`. Вторая поломка: в `main` функция передана без вызова.
4. Добавь скобки: печатать нужно результат `answer()`.
5. «Запустить» — должно быть `42`. Нажми «Проверить».

**Как проверить себя.** В «Результате» одна строка `42`; все четыре галочки зелёные. Функция `answer` осталась отдельной, с результатом `int`, в `main` — ровно один вызов `fmt.Println`.

**Если не принято.**
- Красная «Программа успешно завершилась» → ошибка компиляции не исправлена; читай первое сообщение.
- Печатается адрес вроде `0x…` → нет скобок после `answer`.
- Красная «Обязательная структура задания» → ты убрал функцию `answer`, поменял её тип результата или напечатал число напрямую, минуя `answer()`.

> **Подсказка.** В этом задании не нужно писать новый код — только исправить два места: кавычки и скобки.

### Задание 3 · Две понятные строки

**Цель.** Напечатать две строки двумя отдельными вызовами `fmt.Println`.

**Ожидаемый вывод** — ровно так, две строки:

```text
Имя: Ada
Язык: Go
```

**Шаги.**
1. Выбери задание «Две понятные строки»: `main` снова пустая.
2. Напиши первый вызов `fmt.Println` с текстом `Имя: Ada`.
3. На следующей строке — второй вызов с текстом `Язык: Go`.
4. «Запустить»: сравни порядок строк, двоеточия и пробелы после них.
5. «Проверить».

**Как проверить себя.** Две строки в «Результате» в этом порядке; четыре зелёные галочки.

**Если не принято.**
- Строки поменяны местами или одна строка `Имя: Ada Язык: Go` → нужны два отдельных вызова, по одному на строку.
- Нет пробела после двоеточия или вместо `Ada` написано `Ада` → сравни по символам.
- Красная «Обязательная структура задания» → в `main` должно быть ровно два вызова `fmt.Println`, без других команд печати.

> **Подсказка.** `Println` сам добавляет перевод строки — писать `\n` не нужно.
