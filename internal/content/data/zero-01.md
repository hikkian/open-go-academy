# Что такое компьютер, программа и Go

## Зачем это знать

Когда вы нажимаете кнопку в приложении, компьютер не «понимает» намерение так, как человек. Он выполняет очень простые команды, которые кто-то заранее записал в точном порядке. Понимание этого пути снимает загадочность: если программа не работает, можно выяснить, на каком шаге возникла проблема.

## Компьютер: данные и команды

Компьютер — устройство, которое принимает данные, хранит их, обрабатывает и выдаёт результат. Процессор (CPU, центральный процессор) выполняет машинные инструкции. Память хранит то, с чем компьютер работает сейчас, а накопитель сохраняет файлы после выключения. Клавиатура, экран и сеть помогают вводить и получать данные.

На самом низком уровне данные представлены битами — значениями 0 и 1. Отдельный бит слишком мал, чтобы хранить обычный текст, поэтому биты объединяются в байты (обычно 8 бит). Формат определяет, как трактовать байты: как число, букву, изображение или инструкцию. Один и тот же набор битов может иметь разный смысл в зависимости от формата.

## Файлы и папки

Файл — именованный набор данных. Текстовый файл можно открыть редактором и прочитать; фотография тоже файл, но её байты описывают пиксели. Имя часто заканчивается расширением: `main.go` обычно содержит исходный код Go, `.txt` — обычный текст. Расширение помогает программам выбрать способ обработки, но само по себе не меняет содержимое.

Папка (каталог) группирует файлы и другие папки. Путь показывает, где искать файл. Например, в `course/day1/main.go` папка `course` содержит `day1`, а там находится `main.go`. Путь может быть относительным к текущей папке или полным от корня файловой системы. Команда запуска должна выполняться там, где Go сможет найти нужный файл.

## Операционная система

Операционная система (operating system, OS) управляет аппаратными устройствами и предоставляет приложениям общие услуги: чтение файлов, работу с сетью, памятью и процессами. Windows, macOS и Linux — семейства операционных систем. Приложение просит систему выполнить действие через определённые интерфейсы; ему не нужно самостоятельно управлять каждым электронным сигналом.

Терминал — текстовое окно, где вы вводите команды операционной системе. Он не является обязательным для понимания программирования, но команда `go run main.go` — короткий способ попросить инструменты Go собрать и запустить файл.

## От человеческого текста к выполнению

Исходный код (source code) — инструкции, написанные человеком на языке программирования. Компилятор (compiler) проверяет, соблюдены ли правила языка, и переводит исходный код в форму, пригодную для исполнения. В Go команда `go run` сначала компилирует программу, затем запускает её. Если код нарушает правила, компилятор сообщает об ошибке и не запускает программу.

Схема пути:

```text
main.go (исходный текст) → компилятор Go → исполняемый код → процессор выполняет команды → результат
```

Не путайте три понятия: текст программы — это файл, компилятор — инструмент проверки и преобразования, а работающая программа — процесс, который выполняется сейчас.

## Первая программа Go

Создайте папку для урока и файл `main.go` со следующим содержимым:

```go
package main

import "fmt"

func main() {
    fmt.Println("Привет, Go!")
}
```

Разберём по частям:

- `package main` объявляет пакет исполняемой программы. Пакет — группа связанных объявлений Go.
- `import "fmt"` подключает стандартный пакет `fmt` (format, форматирование), чтобы печатать текст.
- `func main() { ... }` объявляет функцию `main`. Функция — именованный блок команд; запуск обычной Go-программы начинается с `main`.
- `fmt.Println(...)` вызывает функцию `Println` из пакета `fmt`. В круглых скобках передаётся значение; кавычки показывают, что это текстовая строка. `Println` печатает значение и переводит вывод на новую строку.
- Фигурные скобки `{` и `}` ограничивают тело функции. Отступы помогают человеку видеть структуру; Go форматирует их стандартным образом.

В терминале перейдите в папку, где лежит файл, затем выполните:

```sh
go run main.go
```

Ожидаемый результат:

```text
Привет, Go!
```

Если команда `go` не найдена, система не видит установленный Go. Если `stat main.go: no such file or directory`, текущая папка не содержит этот файл. Если сообщение указывает строку и символ, начните читать ошибку с указанного места. После двоеточия компилятор обычно объясняет, что именно ему не удалось разобрать или проверить.

## Текст, числа и результат функции

В программе из примера значение `"Привет, Go!"` — строка (`string`): текст, записанный в двойных кавычках. Целое число (`int`) записывают без кавычек. Поэтому `42` — число, а `"42"` — текст из двух символов. Компилятор не подменяет один тип другим: функция, обещавшая вернуть `int`, должна вернуть число.

Функция может не только выполнять команды, но и вернуть результат. Посмотрите на законченную программу:

```go
package main

import "fmt"

func answer() int {
    return 7
}

func main() {
    fmt.Println(answer())
}
```

Фрагмент `func answer() int` объявляет функцию `answer` без входных значений (`()`), с результатом типа `int`. Команда `return 7` отдаёт число вызывающему коду. В `fmt.Println(answer())` скобки после имени вызывают функцию: сначала получается число `7`, затем оно печатается. Если написать `fmt.Println(answer)` без скобок, это будет имя функции, а не её результат.

Это те же идеи, что понадобятся в упражнении [починить функцию](exercise:repair), где нужно вернуть именно целое число `42` и вызвать функцию.

## Как работать с уроком в браузере

Для упражнений Go устанавливать на свой компьютер не требуется. Выберите карточку задания, изучите условие и начальный файл в редакторе, внесите изменения — черновик сохраняется автоматически. Нажмите **Run (Запустить)**, чтобы получить результат выполнения и сообщения компилятора. Если появилась ошибка, прочитайте имя файла и строку, исправьте код и запустите снова. Когда критерии выполнены, нажмите **Submit (Отправить на проверку)**: проверка покажет результат задания и сохранит подтверждённый прогресс.

Терминал остаётся необязательным способом практики на своём компьютере. Для него понадобится установленный Go; шаги установки есть в [официальной инструкции Go](https://go.dev/doc/install). После установки можно сохранить пример как `main.go` и выполнить `go run main.go` в его папке. Этот путь не нужен, чтобы пройти упражнения в браузере.

## Как диагностировать типичные ошибки

1. Сверьте имя файла и текущую папку. Ошибка поиска файла возникает до разбора Go-кода.
2. Проверьте каждую открывающую скобку и кавычку. Незакрытая `{` часто вызывает сообщение на более поздней строке, чем настоящая причина.
3. Проверьте, что первая строка — `package main`, а функция записана как `func main() {`.
4. Если имя `fmt` неизвестно, добавьте `import "fmt"`.
5. Прочитайте первое сообщение компилятора и его номер строки. Исправляйте одну причину и запускайте снова; последующие ошибки могли быть следствием первой.

Компилятор строг к написанию имён: `Println` и `println` — не одно и то же. Точное сообщение зависит от версии инструмента, поэтому ищите смысл ошибки, а не запоминайте текст дословно.

## Практика

Каждое задание можно решить без ИИ: прочитайте критерии, внесите изменение, запустите программу и сравните stdout с публичным ожидаемым выводом. Эталонное решение намеренно не показывается здесь; сначала попробуйте самостоятельно или запросите его в интерфейсе после попытки.

### Простое — `hello`

Печатайте ровно `Go готов!`. Файл `main.go` уже содержит каркас. Критерий выполнен, если программа компилируется, выводит нужный текст и затем перевод строки.

### Среднее — `repair`

В каркасе две ошибки типов/вызова. Исправьте `answer`, чтобы она возвращала целое число `42`, затем вызовите функцию и напечатайте результат. Не удаляйте отдельную функцию. Ожидаемый вывод: `42` и перевод строки.

### Сложное — `two-lines`

Двумя отдельными вызовами печати выведите `Имя: Ada`, а следующей строкой `Язык: Go`. Проверьте и содержание, и порядок строк.

## Итог и повторение

Теперь вы можете описать путь от текста `main.go` до выполнения инструкций, создать минимальную программу и использовать сообщение компилятора для диагностики. Для повторения через день напишите программу с двумя строками вывода с чистого листа, а затем намеренно удалите кавычку и восстановите программу по сообщению об ошибке. Следующая глава сможет опираться на понимание файлов, путей и выполнения команд.
