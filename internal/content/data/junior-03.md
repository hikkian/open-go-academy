# UTF-8, руны, слова и пределы текстовых правил

## Что ты сделаешь

Ты напишешь три функции: `countRunes` считает кодовые точки в строке, `countWords` разбивает текст на слова и считает их, `reverseRunes` переворачивает строку по рунам. Проверка сравнивает точный вывод, поэтому каждое правило должно быть в тексте задания, а не в догадках.

## Байты и руны

Строка в Go — последовательность байтов в кодировке UTF-8. Один символ может занимать от одного до четырёх байтов: буква `ё` — два, эмодзи — четыре.

```go
package main

import (
    "fmt"
    "unicode/utf8"
)

func main() {
    s := "ёж"
    fmt.Println(len(s), utf8.RuneCountInString(s))
}
```

Вывод: `4 2`. `len` считает байты, `utf8.RuneCountInString` — руны (кодовые точки). Для подсчёта символов нужна вторая функция.

> **Важно.** Руна — это кодовая точка Unicode, а не видимый знак. Видимый знак может состоять из нескольких рун, например `е` и знака ударения.

## Обход строки

`range` по строке выдаёт пары: байтовый индекс и руну. Индексы идут не подряд, потому что многобайтовые символы занимают несколько позиций:

```go
package main

import "fmt"

func main() {
    for i, r := range "ёж" {
        fmt.Println(i, string(r))
    }
}
```

Вывод: `0 ё` и `2 ж`. Индекс `1` пропущен: это вторая половина `ё`, а не отдельный символ.

> **Типичная ошибка.** Считать индексы `range` количеством символов. Для строки «ёж» второй символ стоит на байтовом индексе 2.

## Слова: strings.Fields

`strings.Fields` делит строку по Unicode-пробелам: пробелам, табуляции и переводам строки. Пустые куски отбрасываются, поэтому лишние пробелы ничего не портят. Пунктуация при этом остаётся в словах:

```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    fmt.Println(strings.Fields("  go  Go\tрусский\n"))
}
```

Вывод: `[go Go русский]`. Регистр тоже остаётся как есть: `go` и `Go` — разные строки.

## Переворот по рунам

Чтобы переставить символы, строку превращают в срез рун `[]rune`, меняют местами элементы и собирают обратно:

```go
package main

import "fmt"

func main() {
    r := []rune("кот")
    for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
        r[i], r[j] = r[j], r[i]
    }
    fmt.Println(string(r))
}
```

Вывод: `ток`. Пустая строка даёт пустой срез, и цикл сразу заканчивается.

> **Типичная ошибка.** Переворот по рунам не сохраняет графемы. Знак ударения, который стоит после `е`, при перевороте отрывается от буквы, и смысл меняется. Контракт задания этого и не обещает.

## Если что-то пошло не так

- `imported and not used: unicode/utf8` → импорт есть, а функция из него не вызвана.
- `cannot use r (variable of type []rune) as string value` → перед возвратом нужен `string(r)`.
- `undefined: strings` → не добавлен импорт `strings`.
- Для пустого ввода функция печатает что-то лишнее → проверь, что цикл не обращается к элементам при длине 0.

## Практика

Три задания. Функции проверяются на входах из блока «Ожидаемый вывод»; закрытые примеры видны только в «Проверить».

### Задание 1 · Посчитай руны

**Цель.** Вернуть число рун в строке; пустая строка даёт 0.

**Ожидаемый вывод** — входы `кот` и пустая строка:

```text
3
0
```

**Шаги.**
1. Выбери задание «Посчитай руны»: в файле есть `countRunes` с `return 0`.
2. Добавь импорт `"unicode/utf8"` после `package main`: без лишних импортов файл не компилируется.
3. Верни `utf8.RuneCountInString(text)`.
4. Нажми «Запустить» и сравни два числа с блоком выше.
5. Нажми «Проверить».

**Как проверить себя.** Два числа: `3` и `0`; все три критерия зелёные.

**Если не принято.**
- Для `кот` выходит 6 → вызван `len`, а не подсчёт рун. Для кириллицы байтов больше.
- Закрытый пример с эмодзи не совпал → функция из `utf8` сама учитывает многобайтовые символы; дополнительного кода не нужно.

> **Подсказка.** Одна функция из пакета `utf8` решает задачу целиком.

### Задание 2 · Подсчитай слова по Unicode-пробелам

**Цель.** Разбить текст на слова через `strings.Fields` и вернуть число каждого слова с учётом регистра.

**Ожидаемый вывод** — входы `go Go go` и `  привет<табуляция>мир<перевод строки>`:

```text
{"go":2,"Go":1}
{"привет":1,"мир":1}
```

**Шаги.**
1. Выбери задание «Подсчитай слова по Unicode-пробелам»: в файле есть `countWords` с `return nil`.
2. Создай результат через `counts := make(map[string]int)`, а не через `nil`.
3. Разбей текст на слова: `strings.Fields(text)`. Импорт `"strings"` добавь сам.
4. Для каждого слова увеличь счётчик: `counts[w]++`.
5. Верни `counts`, нажми «Запустить» и сравни с блоком выше.
6. Нажми «Проверить».

**Как проверить себя.** Два JSON-объекта с точными словами; все три критерия зелёные.

**Если не принято.**
- `go` и `Go` считаются одним словом → регистр нельзя менять; ключи берутся как есть.
- Результат печатается как `null` → карта не создана через `make`.
- Закрытый пример с запятой не совпал → пунктуация остаётся в слове; её не удаляй.

> **Подсказка.** Счётчик слова — это `counts[w]++`: отсутствующий ключ начинается с нуля.

### Задание 3 · Разверни текст по рунам

**Цель.** Вернуть строку с рунами в обратном порядке; пустая строка остаётся пустой.

**Ожидаемый вывод** — входы `кот` и пустая строка:

```text
"ток"
""
```

**Шаги.**
1. Выбери задание «Разверни текст по рунам»: в файле есть `reverseRunes`, который пока возвращает вход без изменений.
2. Преврати строку в срез рун: `r := []rune(text)`.
3. Поменяй местами крайние руны, двигаясь к центру, как в примере выше.
4. Верни `string(r)`, нажми «Запустить» и сравни с блоком выше.
5. Нажми «Проверить».

**Как проверить себя.** Два результата в кавычках: `"ток"` и `""`; все три критерия зелёные.

**Если не принято.**
- Результат равен входу → функция не переворачивает руны, а возвращает строку как есть.
- Закрытый пример с эмодзи или китайским текстом не совпал → переворот должен идти по рунам, а не по байтам.
- Паника на пустой строке → цикл должен проверять `i < j`, а не полагаться на длину.

> **Подсказка.** `[]rune(text)` превращает строку в срез кодовых точек, а `string(r)` собирает его обратно.

## Итог

- `len` считает байты, `utf8.RuneCountInString` считает руны; для кириллицы и эмодзи это разные числа.
- `strings.Fields` делит по Unicode-пробелам и не меняет регистр и пунктуацию.
- Переворот идёт по срезу рун; видимые символы из нескольких рун он не сохраняет.
