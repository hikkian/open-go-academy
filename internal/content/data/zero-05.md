# Функции, строки и Unicode

## Зачем нужны функции

В предыдущих главах программа получила значения, выбрала ветку условия и повторила действия циклом. Теперь научимся давать повторяемому действию имя и вызывать его из разных мест. Это помогает разделить большую задачу на маленькие шаги: отдельную часть можно понять, проверить и применить повторно.

Функция (function, функция) — именованный участок программы с входами и, при необходимости, результатом. Объявление `func greet(name string) string` сообщает: функция называется `greet`, принимает один параметр типа `string` и возвращает строку. Вызов `greet("Ада")` передаёт аргумент — конкретное значение — и получает результат. Параметр это имя внутри объявления, аргумент это значение в месте вызова.

```go
package main

import "fmt"

func greeting(name string) string {
    return "Привет, " + name + "!"
}

func main() {
    message := greeting("Ада")
    fmt.Println(message)
}
```

Это законченная программа: сохраните пример в `main.go` и запустите браузерной кнопкой Run. Она печатает `Привет, Ада!`. Вызов сначала вычисляет `greeting`, затем полученная строка присваивается переменной `message`. Оператор `+` для строк соединяет тексты.

## Параметры, результаты и return

После списка параметров в объявлении записывают тип результата. `return` завершает текущий вызов и отдаёт значение туда, где функцию вызвали. Возвращаемое значение обязано иметь объявленный тип: нельзя вернуть текст из функции с результатом `int`. Функция без результата может просто выполнить действие; в этом уроке мы чаще выбираем возвращаемое значение, потому что его легко проверить.

У функции может быть несколько параметров: `func add(a int, b int) int`. Если типы соседних параметров совпадают, допустима короткая запись `func add(a, b int) int`. Вызов `add(2, 3)` передаёт два аргумента в том же порядке. Функции могут вызывать другие функции: `formatGreeting(name)` может сначала получить `greeting(name)`, а затем дописать нужную часть. Такой способ называется композицией (composition, составление из частей).

```go
package main

import "fmt"

func addTax(price int, tax int) int {
    return price + tax
}

func main() {
    total := addTax(100, 12)
    fmt.Println(total)
}
```

Здесь результат равен `112`. Числа выбраны целыми для простоты: реальная денежная программа должна отдельно определить точность и единицы измерения. Не делайте вывод, будто `int` всегда подходит для финансовых расчётов.

## Область видимости

Область видимости (scope, область видимости) — часть кода, где имя доступно. Параметр `name` существует внутри тела `greeting`; вызывающий код не может обратиться к этому локальному имени. Переменная, объявленная внутри функции, тоже локальна ей. Две функции могут иметь локальные переменные с одинаковым именем: это разные значения, потому что у каждого своё место объявления.

```go
package main

import "fmt"

func double(value int) int {
    result := value * 2
    return result
}

func main() {
    answer := double(6)
    fmt.Println(answer)
}
```

Имена `value` и `result` доступны только внутри `double`, а `answer` — внутри `main`. Фигурные скобки ограничивают блок, а функция — отдельная граница. Не пытайтесь пользоваться локальной переменной после закрывающей скобки: компилятор сообщит `undefined`, то есть имя не объявлено в этой области.

## Строки состоят из байтов

Строка Go (`string`) — неизменяемая последовательность байтов. Для обычного текста эти байты часто кодируют UTF-8. Байты — единицы хранения, а не обязательно отдельные символы, которые человек видит. Латинская `A` занимает один байт UTF-8, кириллическая `Я` — два. Поэтому `len("Я")` возвращает `2`, хотя это одна Unicode rune.

Rune (руна) в Go — целочисленное значение Unicode-кода; пакет `unicode/utf8` умеет читать UTF-8 и считать кодовые точки. Например, `utf8.RuneCountInString("Go Я")` считает четыре rune: `G`, `o`, пробел и `Я`. Это не число байтов и не обязательно число видимых знаков.

```go
package main

import (
    "fmt"
    "unicode/utf8"
)

func main() {
    text := "Я"
    fmt.Println(len(text))
    fmt.Println(utf8.RuneCountInString(text))
}
```

Программа выведет `2`, затем `1`. Термин «символ» в бытовой речи неоднозначен, поэтому контракт функции должен точно говорить, что считать. В упражнениях `countRunes` считает Unicode-кодовые точки через `utf8.RuneCountInString`.

## Rune — ещё не всегда один видимый знак

Некоторые видимые знаки складываются из нескольких Unicode-кодовых точек: например буква может сопровождаться отдельной комбинируемой отметкой. Существуют также составные эмодзи. Поэтому подсчёт rune не равен подсчёту графем (grapheme clusters, графемных кластеров) — единиц, которые пользователь воспринимает как один знак. Стандартный пакет Go умеет удобно считать rune, но этот урок не обещает подсчёт графем.

Когда задача просит длину в байтах, используйте `len`. Когда просит число Unicode-кодовых точек, используйте `utf8.RuneCountInString`. Для пользовательского счётчика видимых знаков понадобится отдельная библиотека и чёткий контракт; здесь он не нужен.

## strings и ограниченная нормализация

Пакет `strings` содержит операции над строками. `strings.TrimSpace` удаляет пробельные rune по краям, но сохраняет внутренние пробелы. `strings.ToLower` переводит текст в нижний регистр по правилам Unicode, известным стандартной библиотеке. Эти действия не удаляют пунктуацию, не сжимают несколько внутренних пробелов и не выполняют языковую транслитерацию.

```go
package main

import (
    "fmt"
    "strings"
)

func normalize(text string) string {
    return strings.ToLower(strings.TrimSpace(text))
}

func main() {
    fmt.Println(normalize("  Go ЯЗЫК  "))
}
```

Политика функции — часть её контракта. Если сказано «обрезать края и привести регистр», не добавляйте незапрошенную замену знаков препинания. Пример напечатает `go язык`.

## Как разбирать вызов

Для выражения `greeting("Ада")` проследите четыре шага: найдите объявление; сопоставьте аргумент с параметром; выполните тело до `return`; подставьте возвращённое значение на место вызова. Если функция вызывает другую функцию, повторите путь внутрь и затем вернитесь к месту вызова. Это простая трассировка выполнения, а не особый режим Go.

Частые ошибки: забыть круглые скобки вызова (`greeting` вместо `greeting("Ада")`); вернуть значение неправильного типа; обратиться к локальному имени снаружи; считать `len` числом русских букв. Сначала сверяйте сигнатуру и типы, затем прочитайте самую первую строку ошибки компилятора.

## Практика

Установленный Go не нужен: редактор и запуск доступны в браузере. Решения не показаны в публичном тексте. Для каждой задачи есть конкретная функция и набор открытых примеров.

### Простое — `greet`

Напиши функцию `greet(name string) string`, которая возвращает `Привет, `, затем имя, затем `!`. Например, для `Ада` результат — `Привет, Ада!`. Не печатай результат: верни его.

### Среднее — `countRunes`

Реализуй `countRunes(text string) int`. Верни число Unicode-кодовых точек. Пустая строка содержит ноль rune. Проверь кириллицу: количество rune отличается от `len` в байтах.

### Сложное — `normalizeText`

Обрежь пробелы с обоих краёв и переведи оставшийся текст в нижний регистр. Внутренние пробелы сохраняй. Не удаляй знаки препинания. Результат должен быть строкой, а функция чистой: одинаковый вход даёт одинаковый результат.

## Мини-лаборатория: предскажи до запуска

Перед Run запишите ожидаемые значения для `len("A")`, `len("Я")` и `utf8.RuneCountInString("Я")`. Затем измените текст на `"Go Я"` и повторите прогноз. Такая привычка превращает запуск в проверку гипотезы. Если результат отличается, разложите строку на байты и rune, а не подбирайте случайное преобразование.

Мысленно выполните `greeting("Ада")`: аргумент сопоставляется параметру `name`; тело строит строку; `return` передаёт её назад. Теперь замените аргумент пустой строкой. Функция всё ещё выполняет контракт, хотя результат может выглядеть непривычно. Особое поведение для пустого имени должно быть отдельным правилом.

Строковые преобразования вроде `strings.ToLower` возвращают новое строковое значение. Результат нужно вернуть или присвоить переменной. Это похоже на арифметическое выражение: вычисление `value + 1` само по себе не присваивает новое значение `value`.

Прочитайте сигнатуру вслух: «countRunes принимает строку text и возвращает int». Печать через `fmt.Println` не заменяет `return`: печать отправляет данные наружу, возврат отдаёт значение вызывающему коду. В упражнении тестовый код сравнивает именно возвращённое число.
