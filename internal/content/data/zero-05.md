# Функции, строки и Unicode

## Что ты сделаешь

Ты напишешь три функции: `greet` собирает приветствие, `countRunes` считает символы Unicode, `normalizeText` приводит строку к единому виду. Функции ничего не печатают: они возвращают результат, а проверка сравнивает его с ожидаемым.

## Функция: вход, результат, return

Функция — именованный кусок кода, который можно вызвать с разными значениями. Заголовок описывает контракт:

```go
package main

import "fmt"

func double(n int) int {
    return n * 2
}

func main() {
    fmt.Println(double(4))
}
```

В `func double(n int) int` имя `n` — параметр (parameter): имя и тип входа внутри функции. В `double(4)` число `4` — аргумент (argument): конкретное значение при вызове. `return` отдаёт результат туда, откуда вызвали, и на этом функция заканчивается.

Вывод программы:

```text
8
```

> **Важно.** Функция возвращает значение, а не печатает его. Если ты вызовешь `fmt.Println` внутри `greet`, проверка увидит печать, а не результат.

## Область видимости

Имя, объявленное внутри функции, живёт только внутри неё. Переменная `result` из `double` снаружи не видна:

```go
package main

import "fmt"

func double(n int) int {
    result := n * 2
    return result
}

func main() {
    fmt.Println(double(4))
}
```

Попробуй добавить в `main` строку `fmt.Println(result)`: компилятор остановится, потому что имени `result` в `main` нет.

> **Типичная ошибка.** Использовать локальную переменную после функции. Компилятор ответит `undefined: result`: имя существует только в своей функции.

## Байты и руны

Строка в Go — последовательность байтов. Для латиницы байт совпадает с символом, для кириллицы — нет: буква «Я» занимает два байта в UTF-8. Поэтому `len` считает байты, а число символов (rune) даёт `utf8.RuneCountInString`:

```go
package main

import (
    "fmt"
    "unicode/utf8"
)

func main() {
    fmt.Println(len("Я"), utf8.RuneCountInString("Я"))
}
```

Вывод: `2 1`. Пустая строка даёт `0` в обоих случаях. Rune не всегда равна видимому знаку: буква `é` может состоять из двух rune, и стандартная библиотека не склеивает такой «видимый знак».

> **Типичная ошибка.** `len(text)` для «Я» даёт 2, а не 1. Для подсчёта символов бери `utf8.RuneCountInString`.

## Пробелы и регистр

`strings.TrimSpace` убирает пробельные символы только по краям строки, внутренние пробелы остаются. `strings.ToLower` переводит буквы в нижний регистр:

```go
package main

import (
    "fmt"
    "strings"
)

func main() {
    fmt.Println(strings.TrimSpace("  Go  "), strings.ToLower("ЯЗЫК"))
}
```

Вывод: `Go язык`. Первую строку обрезали по краям, вторую перевели в нижний регистр.

## Если что-то пошло не так

- `undefined: greet` → функция названа не так, как в задании. Имя совпадает с учётом регистра.
- `undefined: utf8` или `undefined: strings` → не добавлен импорт. В стартовом файле импортов нет: добавь их сам, после `package main`.
- `imported and not used` → импорт есть, а функции из него не вызываются.
- `missing return` → в какой-то ветке функция не возвращает значение.
- `cannot use ... as int value` → тип результата не совпадает с написанным после скобок.

## Практика

Три задания. Функции проверяются на входах из блока «Ожидаемый вывод»; закрытые примеры видны только в «Проверить».

### Задание 1 · Составь приветствие

**Цель.** Вернуть строку «Привет, <имя>!» из функции `greet`.

**Ожидаемый вывод** — «Запустить» вызывает `greet` на входах `Ада` и `Go` и печатает результаты в кавычках, по одному в строке:

```text
"Привет, Ада!"
"Привет, Go!"
```

**Шаги.**
1. Выбери задание «Составь приветствие»: в файле есть `greet` с пустым `return ""`.
2. Замени `return ""` строкой, которая склеивает `"Привет, "`, имя и `"!"` через `+`.
3. Нажми «Запустить» и сравни обе строки с блоком выше.
4. Нажми «Проверить».

**Как проверить себя.** В «Результате» два приветствия в кавычках; все три критерия зелёные; статус «Принято».

**Если не принято.**
- Нет пробела после запятой → строка `Привет,Ада!`: пробел стоит внутри текста `"Привет, "`.
- Красная «закрытый пример» с пустым именем → для пустого имени функция возвращает приветствие без имени: `Привет, !`.
- Красная «пример 1» при правильном тексте → проверь восклицательный знак в конце.

> **Подсказка.** Оператор `+` склеивает строки в одну. Кавычки в коде не попадают в результат: они лишь обозначают текст.

### Задание 2 · Посчитай rune

**Цель.** Вернуть число Unicode-символов (rune) в строке, а не число байтов.

**Ожидаемый вывод** — Входы `Go` и `Я`:

```text
2
1
```

**Шаги.**
1. Выбери задание «Посчитай rune»: в файле есть `countRunes` с `return 0`.
2. Добавь импорт `"unicode/utf8"` после `package main`.
3. Замени `return 0` на `return utf8.RuneCountInString(text)`.
4. Нажми «Запустить» и сравни два числа с блоком выше.
5. Нажми «Проверить».

**Как проверить себя.** Два числа в «Результате»: `2` и `1`; все три критерия зелёные.

**Если не принято.**
- Для `Я` выходит 2 → вызван `len(text)`, а не подсчёт rune.
- `imported and not used` → импорт есть, но функция не вызвана.
- Закрытые примеры не совпали → проверь, что функция возвращает результат `utf8.RuneCountInString` без дополнительных правок.

> **Подсказка.** Одна функция из пакета `utf8` решает задачу целиком: передай ей `text` и верни её результат.

### Задание 3 · Нормализуй пробелы и регистр

**Цель.** Обрезать пробельные символы по краям и перевести текст в нижний регистр.

**Ожидаемый вывод** — Входы `"  Go ЯЗЫК  "` и `" Уже  Два  "`:

```text
"go язык"
"уже  два"
```

**Шаги.**
1. Выбери задание «Нормализуй пробелы и регистр»: в файле есть `normalizeText` с `return ""`.
2. Добавь импорт `"strings"` после `package main`.
3. Сначала обрежь края: `strings.TrimSpace(text)`.
4. Затем переведи результат в нижний регистр: `strings.ToLower(...)`. Внутренние двойные пробелы не трогай.
5. Нажми «Запустить» и сравни с блоком выше, включая двойной пробел в `"уже  два"`.
6. Нажми «Проверить».

**Как проверить себя.** Две строки в кавычках; внутренние пробелы сохранены; все три критерия зелёные.

**Если не принято.**
- В результате `уже два` с одним пробелом → функция сжала внутренние пробелы. Меняй только края и регистр.
- Заглавные буквы остались → `ToLower` не применён к результату.
- Красная «закрытый пример» на строке из одних пробельных символов → такая строка даёт пустой результат.

> **Подсказка.** Порядок важен: сначала `TrimSpace`, потом `ToLower`. Оба вызова принимают строку и возвращают строку.

## Итог

- Функция принимает параметры и возвращает результат через `return`; печатать результат должна программа, а не функция.
- `len` считает байты, `utf8.RuneCountInString` — rune; для кириллицы это разные числа.
- `strings.TrimSpace` срезает края, `strings.ToLower` меняет регистр; внутренние пробелы остаются.
