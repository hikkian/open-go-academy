# План переписывания уроков по шаблону карточек

Шаблон: `docs/LESSON_STYLE_GUIDE.md` + `docs/LESSON_TEMPLATE.md`. Интерфейс: `docs/LESSON_UI_SPEC.md`. Образцы: `zero-01`, `zero-02`, `zero-03` (сделаны в задаче OGAUX1).

## Объём

128 уроков в `internal/content/manifest.json`: Zero 8 (3 готовы), Junior 12, Junior+ 20, Middle 40, Middle+ 24, Senior 24. Остаётся 125. У каждого — `.md` + `.json`; проверки (`internal/grading/specs`, эталоны, `public_output`, `starter_code`, `id`/`title`) не меняются.

## Роли

- **Fable** — образцы (первый урок каждого ранга: `zero-04`, `junior-01`, `juniorplus-01`, `middle-01`, `middleplus-01`, `senior-01`), выборочная проверка качества каждой пачки (первый урок пачки целиком + 20 % случайно, зерно = дата), ведение этого плана.
- **Haiku** (дорожка `claude`) — переписывание пачками по шаблону: один урок = один коммит в репозитории; на входе — файл урока, шаблон, образец ранга, список неприкосновенного; на выходе — `.md`, `.json` (только `prompt`, `criteria`, `self_check`, `learning_outcomes`), результат лёгкой проверки.
- **Исполнитель кода** (Codex, отдельная задача OGAUX2 по `LESSON_UI_SPEC.md`) — карточка над редактором, «ждали / получили», выноски, чипы заданий. Контент от него не зависит: карточки читаются и в старом интерфейсе.

## Неприкосновенное (ломает тесты)

- Заголовки уроков и названия упражнений, на которые опираются тесты: «Что такое компьютер, программа и Go», «Поздоровайся с компьютером», «Значения, переменные и простые типы», «Функции, строки и Unicode», «SQL с нуля: таблицы и CRUD», «Первый HTTP-сервер на net/http»; фраза «Практический мост: от модели к реальному параллельному worker-у» в уроке Middle о конкурентности; заголовок «P5 defense и независимый review» в `senior-23`; `zero-01`: ровно 3 упражнения с id `hello`, `repair`, `two-lines` и ровно 5 вопросов самопроверки.
- Для 88 уроков Middle/Middle+/Senior: 1800–2200 слов в `.md`, ≥ 3 групп Go-примеров, уникальные `learning_outcomes` и пары вопрос/ответ (`scripts/test_m11_curriculum_quality.py`), тематические маркеры Middle 01–14 (P3-мосты), Middle 21–37 (лабы), Middle+ 13–23 (введения) — читать тест перед правкой этих уроков.
- Все ```` ```go ```` блоки запускаются тестом `TestEveryPublishedGoExample…`: сломанный код только в ```` ```text ````.
- Ссылки только `lesson:`, `exercise:`, `#заголовок`, `https://`.

## Пачки и сроки

Ориентир: Haiku делает 4–6 уроков за сессию при длине 1200 слов и 2–3 — при 2000 слов; Fable тратит на проверку пачки около часа. Сроки — календарные при параллельной работе двух дорожек; они не включают ожидание тихих окон для тяжёлых ворот.

|---|---|---|---|---|
| Z | zero-04…08 (5) | Fable образец zero-04, Haiku остальные | неделя 1 | лёгкая проверка каждого урока; `go test ./internal/content -run 'TestCatalog\|TestAllGoCodeBlocks\|TestEveryPublished.*/zero'` в тихое окно |
| J | junior-01…12 (12) | Fable junior-01, Haiku 11 | неделя 1–2 | то же для `junior` |

| M | middle-01…40 (40) | Fable middle-01 + 01–14 проверка мостов, Haiku 39 | неделя 3–5 | `python3 -m unittest discover -s scripts -p 'test_m11_curriculum_quality.py'` после каждого урока (лёгкий, секунды) |

Лёгкая проверка урока (можно на занятой машине, под `nice`): JSON читается; `### Задание N · title` совпадают с упражнениями; все go-блоки — `go vet`/`go run` по одному файлу через `sh scripts/go.sh`; счётчик слов в контракте ранга; ссылки по правилам `content.go`; чеклист §7 руководства по стилю. Скрипт: `python3 scripts/check_lesson_template.py <id…>` (есть; подключить к `make test` как лёгкий unittest — первая задача пачки Z).

## Порядок внутри урока (для Haiku)

1. Прочитать `.json`: упражнения, `public_output`/спецификацию, критерии; прочитать `.md`.
2. Составить карточки по §4 руководства: цель, ожидаемый вывод (для функциональных — публичные входы и результаты из `internal/grading/specs/<id>.json`), шаги, самопроверка, «если не принято» с названиями реальных галочек, подсказка.
3. Сократить теорию до разделов ≤ 150 слов с примером; убрать мини-глоссарий, повтор условий, «вернитесь через день»; добавить выноски.
4. Обновить `prompt` (≤ 90 знаков), `criteria` (по галочкам), `self_check`, `learning_outcomes` при необходимости.
5. Запустить лёгкую проверку; для Middle+ — счётчик слов 1800–2200.
6. Коммит от имени git-личности репозитория: `lesson <id>: task cards and short sections`; без push.

## Риски

- Контент опережает интерфейс: до OGAUX2 карточки выглядят как обычный текст с цитатами. Это приемлемо (структура уже помогает), но «Подсказка» не скрыта — она не должна раскрывать решение.
- Контракт 1800–2200 слов у продвинутых уроков: карточки добавляют ~300 слов, значит проза сокращается на столько же; при переписывании считать слова на каждом шаге.
- M11 gate тяжёлый и требует тихой машины: планировать одно окно в конце, не блокировать им пачки.
