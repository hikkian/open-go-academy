Open Go Academy — signed project review flow
Date: 2026-10-16
Scope: local single-user P3/P4/P5 manual-review evidence; this does not enable rank awards.

Implemented:
- Offline Ed25519 reviewer key generation, strict registry loading, canonical signing and signature verification.
- Server review packet bound to the exact current project version, submission, passing evaluation, submitted files, artifact hash and versioned manual rubric. The packet contains an unsigned attestation template whose artifact/rubric hashes are directly consumable by the signer.
- POST persistence is append-only and replay-idempotent; GET history returns persisted decisions without the raw signature.
- Workspace exports a packet, imports signed JSON, restores only an untrusted submission/evaluation pointer from localStorage and revalidates it against the server before showing review controls/history.
- Reviewer signatures prove only possession of an operator-pinned key. The local system does not prove real-world identity or reviewer independence. Manual decisions do not award rank; the advanced-rank guard remains closed.
- Canonical Base64 verification closes alternate-encoding replay; project evidence-linked exam attempts are protected from retention pruning.
