# Advanced exam grader correction — 2026-10-16

An independent review found that the first Middle/Middle+/Senior exam references used a few outputs that disagreed with the course grading specifications, while their test vectors checked a separate hand-written table. Those vectors could pass even though a learner submitting the reference would fail the actual grader.

The advanced exams now use nine exam-only grading specs under `internal/grading/specs/`, separate from the mandatory final-lesson exercise specs. They cover retry/backoff/commit conditions (Middle), benchmark samples with independent medians, SLO budget and fault gates (Middle+), and risk prioritization, complete decision-review state combinations, and release gates (Senior). Each has public and hidden cases. `internal/assessment/advanced_test.go` now compiles each trusted reference with the actual grader driver, sends its public+private inputs, and asserts `grading.Spec.Check` passes.
