Finding and correction
The three existing function signatures receive only run counts (and, for Medium/Hard, a bool). Prompts previously claimed these values also proved a Go version, dataset hash, same input, or the execution of an actual fault test. Those claims were removed. Contracts now describe only what the signatures can inspect:
- Easy: either non-positive run count -> incomplete; otherwise compare.
- Medium: either count below three -> repeat; otherwise false faultTested -> fault_test, true -> review.
- Hard: true iff both counts are at least three and faultTested is true.
The lesson now says Go version, input identity/hash, raw results, and a fault-test artifact must be recorded separately. The helper cannot inspect them and does not promise reproducibility across machines or an SLA. The existing references implement the corrected rules; signatures stayed unchanged.
