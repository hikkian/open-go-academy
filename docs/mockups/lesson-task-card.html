ЗАДАНИЕ 1 · ПОЗДОРОВАЙСЯ С КОМПЬЮТЕРОМ · простое

Цель: напечатать ровно одну строку «Go готов!»

ОЖИДАЕМЫЙ ВЫВОД — ровно так

Go готов!⏎

ШАГИ

  1. Внутри func main() напиши вызов fmt.Println с этим текстом в кавычках.
  2. Нажми «Запустить» и сравни вывод с блоком выше.
  3. Нажми «Проверить».

ЧТО ПРОВЕРИТСЯ

  • Программа компилируется и завершается без ошибки
  • Вывод — ровно «Go готов!» и перевод строки
  • Ничего лишнего в выводе
  • В main есть вызов fmt.Println
Подсказка

Текст между кавычками должен совпасть буква в букву — сравни со строкой «Ожидаемый вывод», включая восклицательный знак.

1package main
2
3import "fmt"
4
5func main() {
6 fmt.Println("Привет, Go!")
7}
