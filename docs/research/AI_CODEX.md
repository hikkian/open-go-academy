## Стоимость и продуктовый gateway

По полученной официальной таблице Standard short-context на 2026-10-15 за 1M tokens: Luna input $0.10 / output $0.50, Sol 6.1 input $2 / output $10; cached input отдельно $0.01/$0.10. Это API цены, не единицы подписки Codex. Long context, service tier, cache writes, tools могут изменить стоимость. Источник https://developers.openai.com/api/docs/pricing ; проверка source-verification.json. Никакие API вызовы с оплатой не выполнялись, ключ не требуется для core курса.

M8: gateway на сервере, OpenAI-compatible endpoint отдельно от подписки. No-AI по умолчанию. Разрешённый явно выбранный provider + consent на отправку source; fixed timeout, bounded retry, quota reservation до запроса, точный token usage где provider возвращает, approximate cost label иначе. Кэш только безличных ответов с lesson/content/provider version; failover без неожиданного перехода на платный endpoint. Compiler/tests/progress/rank deterministic, LLM не подписывает и не присваивает ранг. Ошибки/quota/redaction проверять mock-provider tests. Источники https://developers.openai.com/api/docs/guides/rate-limits и https://developers.openai.com/api/docs/guides/prompt-caching . Gateway пока не реализован.
