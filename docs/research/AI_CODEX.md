# Codex и AI: проверка 2026-10-16

Повторная локальная проверка: `codex-cli 0.162.0-alpha.17.2`; `codex features list` показывает `multi_agent stable true` и `api_key_model_discovery stable true`. `multi_agent_v2 stable false`; конфигурация проекта на него не опирается. Проектные `[agents]` ключи валидны по официальной схеме: `enabled`, `max_concurrent_threads_per_session`, `default_subagent_model`, `default_subagent_reasoning_effort`; роли builder/researcher настроены на `gpt-6-luna`, reviewer на `gpt-6.1-sol`. В этом живом запуске builder-задачи реально работают; параллелизм ограничен тремя дочерними агентами. Имена runtime-моделей, которые показывает подключённая среда: `gpt-6.1-sol`, `gpt-6-astra`, `gpt-6-sol`, `gpt-6-luna`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`. Список не доказывает прямой API-доступ ко всем вариантам; доступность проверяется фактическим запуском. Доли использования и reset times изменяются, поэтому читаются актуальным `get_usage_limits`, а не сохраняются как стабильные свойства клиента. Изменение конфигурации не меняет уже начатую сессию.

Источники: https://learn.chatgpt.com/docs/agent-configuration/subagents , https://learn.chatgpt.com/docs/config-file/config-reference , https://developers.openai.com/codex/config-schema.json , https://learn.chatgpt.com/docs/models . Модели из действующего runtime: GPT-6.1 Sol, GPT-6 Astra, GPT-6 Sol, GPT-6 Luna, GPT-5.6 Sol; доступность отдельного API этим не установлена. Числа лимитов аккаунта не запрашивались, расход не обещаем уменьшить на конкретный процент.

## Стоимость и продуктовый gateway

По полученной официальной таблице Standard short-context на 2026-10-15 за 1M tokens: Luna input $0.10 / output $0.50, Sol 6.1 input $2 / output $10; cached input отдельно $0.01/$0.10. Это API цены, не единицы подписки Codex. Long context, service tier, cache writes, tools могут изменить стоимость. Источник https://developers.openai.com/api/docs/pricing ; проверка source-verification.json. Никакие API вызовы с оплатой не выполнялись, ключ не требуется для core курса.

M8 реализован: server-side provider gateway использует OpenAI-compatible endpoint отдельно от подписки Codex, no-AI остаётся режимом по умолчанию. Требуются выбранный provider и согласие на отправку исходника; заданы timeout, bounded retries и предварительный quota reservation. Точные расходы доступны, если provider возвращает token usage; иначе UI показывает оценку. Компилятор, тесты, прогресс, экзамены и ранг остаются детерминированными; LLM не подписывает credentials и не присваивает ранг. Mock-provider проверяет ошибки/quota/redaction. Реальный платный API не вызывался. Источники https://developers.openai.com/api/docs/guides/rate-limits и https://developers.openai.com/api/docs/guides/prompt-caching .
