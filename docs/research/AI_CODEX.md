# Codex и AI: проверка 2026-10-16

Локальная проверка 2026-10-18: `codex-cli 0.163.0-alpha.10.2`; `codex features list` показывает `multi_agent stable true` и `api_key_model_discovery stable true`, а `multi_agent_v2 stable false`. Актуальный проектный `.codex/config.toml` использует `enabled=true`, не более трёх дочерних потоков и `gpt-6-luna` по умолчанию; `.codex/agents/` назначает builder/researcher на `gpt-6-luna`, reviewer на `gpt-6.1-sol`. Эта сессия фактически запустила обе роли; доступность этих моделей подтверждена runtime, не только конфигурацией. Codex model picker/tool metadata также перечисляет `gpt-6-astra`, `gpt-6-sol`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`; наличие в списке не доказывает их доступность конкретной учётной записи или в API, поэтому не используем их без runtime-проверки. Доли использования и reset times изменяются, поэтому читаются актуальным `get_usage_limits`, а не сохраняются как стабильные свойства клиента. Изменение конфигурации не меняет уже начатую сессию.

Источники: https://learn.chatgpt.com/docs/agent-configuration/subagents , https://learn.chatgpt.com/docs/config-file/config-reference , https://developers.openai.com/codex/config-schema.json , https://learn.chatgpt.com/docs/models . URL и SHA256 полученных документов доступны в evidence/source-verification.json; целые сторонние документы не включены в репозиторий. Модели из действующего runtime: GPT-6.1 Sol, GPT-6 Astra, GPT-6 Sol, GPT-6 Luna, GPT-5.6 Sol; доступность отдельного API этим не установлена. Числа лимитов аккаунта не запрашивались, расход не обещаем уменьшить на конкретный процент.

## Стоимость и продуктовый gateway

По полученной официальной таблице Standard short-context на 2026-10-15 за 1M tokens: Luna input $0.10 / output $0.50, Sol 6.1 input $2 / output $10; cached input отдельно $0.01/$0.10. Это API цены, не единицы подписки Codex. Long context, service tier, cache writes, tools могут изменить стоимость. Источник https://developers.openai.com/api/docs/pricing ; проверка source-verification.json. Никакие API вызовы с оплатой не выполнялись, ключ не требуется для core курса.

M8 реализован: server-side provider gateway использует OpenAI-compatible endpoint отдельно от подписки Codex, no-AI остаётся режимом по умолчанию. Требуются выбранный provider и согласие на отправку исходника; заданы timeout, bounded retries и предварительный quota reservation. Точные расходы доступны, если provider возвращает token usage; иначе UI показывает оценку. Компилятор, тесты, прогресс, экзамены и ранг остаются детерминированными; LLM не подписывает credentials и не присваивает ранг. Mock-provider проверяет ошибки/quota/redaction. Реальный платный API не вызывался. Источники https://developers.openai.com/api/docs/guides/rate-limits и https://developers.openai.com/api/docs/guides/prompt-caching .
