# Начало работы

Open Go Academy запускается локально. Требуются Linux, Go 1.27.2 (если локальной версии нет, `scripts/go.sh` загрузит закреплённый toolchain через `make bootstrap`), Node.js 24.18.0, npm и make. Для выполнения учебного Go-кода дополнительно нужен rootless Podman с cgroup v2/systemd и seccomp. Версии и ограничения — в [матрице версий](docs/research/VERSION_MATRIX.md), [архитектурном обзоре](docs/architecture/OVERVIEW.md) и основном [README](README.md).

Проверенная среда — Linux; есть дополнительные, пока не проверенные инструкции для [Windows/WSL 2](docs/INSTALL_WINDOWS_WSL.md) и [macOS/Linux VM](docs/INSTALL_MACOS.md). Если среда не подтверждает необходимые Linux sandbox features, оставьте runner выключенным.

## Установка

Из корня репозитория:

```sh
make bootstrap
make build
```

Bootstrap скачивает закреплённый Go toolchain/зависимости, npm пакеты, Chromium и OCI image. Это требует сети и диска. Команда не нужна для уже подготовленной установки. Не запускайте сервис на публичном интерфейсе.

## Запуск

В первом терминале:

```sh
make runner
```

Во втором:

```sh
make dev
```

Откройте `http://127.0.0.1:8380`. Создайте локальный профиль, откройте урок, отредактируйте Go-код и проверьте выполнение. Если runner/runtime отсутствует или preflight завершается ошибкой, выполнение должно быть недоступно; не обходите эту проверку. Runner — локальный single-user режим, не публичный sandbox.

## Проекты P2 и далее

Для локальной сборки project-runner следуйте командам и состоянию из [README](README.md) и [handoff](AGENT_HANDOFF.md). Не запускайте Compose-файлы проекта через host Docker/Podman. Project-runner использует собственные зафиксированные OCI профили; отсутствие профиля означает, что действие недоступно.

## Данные и остановка

Остановите процессы `Ctrl+C`. База, сессия и ключи находятся в `.data/`; не удаляйте и не публикуйте их. Для полного backup остановите API и сохраните в защищённом месте `academy.db`, `session.secret` и `issuer.key` из активной директории данных; если её путь изменён конфигурацией, копируйте соответствующий каталог. Ключ подписи нужен для уже выданных credentials. Подробности и ограничения восстановления — в основном [README](README.md). `.env` автоматически не загружается. AI-провайдер не требуется; AI Tutor включается отдельно пользователем.

## Проверки разработчика

```sh
make test
make sandbox-test
python3 scripts/crash-check.py
```

Для Playwright E2E сначала запустите API и нужные runner-процессы, затем выполните `make e2e`. Команды и особенности описаны в [CONTRIBUTING.md](CONTRIBUTING.md). Проверенный профиль ограничен локальным Linux/rootless режимом; Windows/macOS не прошли проверку и остаются экспериментальными. M0–M13 acceptance пройдены для этого заявленного scope; публичный multi-tenant runner и публикация GitHub не включались. Сообщайте об ошибках с версией ОС, точной командой и сокращённым текстом ошибки; удаляйте секреты и личные данные.
