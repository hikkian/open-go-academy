# P5 reference — один возможный вариант

Этот пакет показывает, как может выглядеть обоснованная работа, но не является production-ready сервисом и не выдаёт студенту учебный ранг. Его центральный эксперимент моделирует риск повторной доставки и проснувшегося stale worker: после повторной выдачи lease результат принимается только от владельца актуального fencing token.

## Проверка prototype

Нужен Go 1.27.2. В каталоге `reference/`:

```sh
go test -count=1 ./...
go test -race -count=1 ./...
go vet ./...
go build ./...
go run .
```

Тесты детерминированы: lease time передаётся явно, `time.Sleep` не используется. In-memory mutex гарантирует согласованный переход только внутри одного процесса; реальная архитектура ниже использует SQL-транзакции, условные обновления, а downstream всё равно обязан поддержать idempotency или reconciliation.
