# P1 — Go CLI Toolkit

Реализуйте CLI по функциональному заданию, ограничениям и критериям приёмки в `../README.md`. Начальный код намеренно возвращает ошибку `TODO`: это учебная заготовка, а не готовая команда. Цель для обработки ошибок — структура `ToolError` с полем `Message` и методом `Error() string`; подключите её к `run` и точке входа.

Проверьте результат командами `go test ./...`, `go vet ./...` и `go build -o toolkit .`. Добавьте тесты на успешные команды и ошибки, прежде чем считать этап завершённым.
